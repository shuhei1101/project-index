## 要望

管理用の YAML に次の 8 件のファイルの行を追加し、管理の MCP の `check_project` が返す索引の同期の管理用の YAML に無いファイルを 0 件にする。

| 管理用の YAML | 追加する行の `path` |
| --- | --- |
| [src/files.yaml](https://github.com/shuhei1101/project-index/blob/d01cc35033050686d7e50b6e2ecc379186411544/src/files.yaml) | `project_index/features/write/direct_commit.py`・`project_index/features/write/route.py`・`project_index/features/write/secrets.py` |
| [tests/files.yaml](https://github.com/shuhei1101/project-index/blob/d01cc35033050686d7e50b6e2ecc379186411544/tests/files.yaml) | `integration/server/test_commit_documents.py`・`unit/project_index/features/write/test_direct_commit.py`・`unit/project_index/features/write/test_route.py`・`unit/project_index/features/write/test_secrets.py`・`unit/project_index/shared/test_version.py` |

<!-- /table -->

追加した後に、次を確認する。

- `check_project` の索引の同期が、管理用の YAML に無いファイル・ファイルが無い行・`metadata` の列が無い文書をどれも 0 件で返す
- `search_docs` を `filter`（`path` の `eq`）で呼び、8 件の行が返る

`src/`・`tests/` の `.py` のうち、管理用の YAML に行の無いファイルは、`check_project` の対象外の `__init__.py` を除けばこの 8 件だけで、同じ型の漏れはほかに無い。
