## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| MCP の接続 | `.mcp.json` で文書の MCP と管理の MCP を `PROJECT_INDEX_PORT` の索引のサーバーへつなぐ | - |
| SessionStart のフック | ポートにつながらなければ `project-index serve` を切り離して起動し、再接続の案内か起動できない理由を文脈に入れる。`/clear`・圧縮の後はセッションの返し済みの記録を削除する | dev-docs#163 で dev-docs のフックに残る画面のサーバーの起動とは分ける |
| PreToolUse のフック | project-index の文書の MCP のツールの入力に `cwd`・`session_id`・`agent_id` を入れて返す | 対象のツール名は project-index の MCP サーバー名に合わせる |
| `global-setup` | 端末に project-index のクローン・依存・端末の設定・Claude Code の env を用意し、`/mcp` につながることを確かめる | - |
| `setup` | フォルダを配信元として端末の設定に並べ、配信元の設定を既定の名前 `project-index.yaml` で作る・検査する | dev-docs#163 は配信元の登録を project-index のスキルへ移す案を推奨している |
