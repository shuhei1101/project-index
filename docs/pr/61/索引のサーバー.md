## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 入れ替えの通知 | `_publish` の後の位置の行を除外する分岐で、組を入れ替えた後に `_on_rebuilt` を新しく配信する配信元で呼ぶ（`get` の組み立て直しと同じく `_reload_lock` を持ったまま） | 新しいインターフェースを追加せず、registry が持つ `on_rebuilt` を使用する |
| 呼ばない場合 | 入れ替えが起きない `_publish`（ID が重ならない・先の位置の行が配信中で今の行を除外する）では呼ばない | - |
| キャッシュの破棄 | `main.py` の `on_rebuilt`（渡した配信元で `discard_source_caches` を呼ぶ）を使用する | - |
| 既存機能への影響 | 設定の誤り（`sources[{n}].id` の重複）のときだけ通る経路で、`status` の応答は変わらない | - |
