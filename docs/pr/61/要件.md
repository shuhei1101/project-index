# 要件

## 要望

起動の `load` で、後の位置の行が先に読み込まれて配信された後に、同じ ID の先の位置の行を読み込んで配信する行を入れ替えたとき、文書のストア・文書の検査・変換のキャッシュを破棄し、入れ替えた後の配信元で検査し直す。
入れ替えた後の文書の読み取りは、`reload` をしなくても先の位置の行の文書を返却する。
入れ替えが起きない読み込み（ID が重ならない行・先の位置の行が先に読み込まれた場合）ではキャッシュを破棄しない。
