## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 読み取りの結果のキャッシュのキー | 今のキーに、validators の行の定義のハッシュ・スクリプトの内容を表す値・参照する場所（クローン本体か worktree か）を加える | 値の作り方はモジュール構成設計で決める |
| スクリプトの内容 | worktree では作業ツリーのスクリプトのファイルの内容、クローン本体ではスクリプトを取り出す commit（`config_commit`）をキーに含め、commit していない書き換えでも次の呼び出しから検査し直す | 内容を求める処理が読み取りの上限（#82）の内に収まるかをモジュール構成設計で確認する |
| 書き込みの検査 | 今までどおりキャッシュしない | - |
| 既存機能への影響 | 入出力の構造は変えない。`reload` で全てのキャッシュを捨てる振る舞い（`clear`）は保つ | - |
