# 要件

## 要望

`on: read` の検査（`validators[]`）が、参照する場所の validators の行とスクリプトで検査した結果を返却し、変わる前の結果を返却しない。

| 参照する場所 | 終わりの条件 |
| --- | --- |
| worktree | worktree の `project-index.yaml` で validators の行（`run`・`on` など）を変えた後と、行が指すスクリプトのファイルを書き換えた後、その worktree を指した読み取りが、変えた後の行とスクリプトで検査した結果を返却する |
| クローン本体（`default_ref`） | `default_ref` が進んで validators の行かスクリプトが変わった後、配信中の設定の行と、スクリプトを取り出す commit（`config_commit`）のスクリプトで検査した結果を返却する |

- worktree の変更は、commit していない状態・commit して push した状態のどちらでも、次の呼び出しから変えた後で検査する。`reload`・再起動を要さない
- 同じ文書を、同じ行・同じスクリプト・同じ参照する場所で検査するときは、2 回目からキャッシュを使い回し、スクリプトを動かし直さない
- worktree とクローン本体で行かスクリプトが違うとき、片方のキャッシュをもう片方へ返却しない
- 書き込みの検査（`on: write`）は今までどおりキャッシュしない
