## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 共通のキー | `METADATA_KEYS` に `visibility` を追加する | `search_docs` では文字列のキーになる（`ARRAY_METADATA`・`NUMBER_METADATA` には入れない） |
| 文書の一覧・文書の取得 | `_metadata` は変えず、`resolve_metadata` が入れた値をそのまま返却する | 応答の形は変えない |
| 設計書 | MOD-25 の `METADATA_KEYS` の値と、IF-24・IF-25 の応答の例の `commonKeys` に `visibility` を追加する | - |
| 既存機能への影響 | 共通のキーが 1 つ増える。既存の応答のキーは変えない | 破壊的変更なし |
