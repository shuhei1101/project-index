# 要件

## 要望

`visibility` を共通のキー `METADATA_KEYS` へ追加し、文書のストアが `resolve_metadata` で解決した値を、読み取り API の応答で返却する。
応答の形は変えない。

| 対象 | 終わりの条件 |
| --- | --- |
| 文書の一覧（IF-24） | `visibility` を持つ文書の `documents[].visibility` が文書の値になり、`common_keys=true` の `commonKeys` も `visibility` を持つ。持たない文書は `null` |
| 文書の取得（IF-25） | `metadata.visibility` と `metadata.commonKeys.visibility` が文書の値になる |
| 共通のキーの扱い | 他の共通のキーと同じく、配信元の設定の行の `metadata` で列名を対応づけられ、`search_docs` の `fields`・`filter`・`group_by` で文字列のキーとして使える |
