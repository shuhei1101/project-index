## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 設計書の種類のスキーマ | `project-index.yaml` の各行の `schema` を knowledge の `schemas/design/{種類}.schema.yaml`（`ref` は knowledge の最新の `design-schemas/v{バージョン}` のタグ。`layout` の行も同じタグへそろえる）へ切り替え、`schemas/` のコピーを削除する | [#70](https://github.com/shuhei1101/project-index/pull/70) がコピーだけに加えた `tags` と用語集の種類は、参照先の knowledge のスキーマが持つことを確認する |
| 管理用の YAML のスキーマ | `files_guide`・`src`・`tests`・`plugin` の行の `schema` を knowledge の `schemas/knowledge-files.schema.yaml` の参照にし、`schemas/files.schema.yaml`・`schemas/phase.schema.yaml` を削除する | 管理用の YAML の 1 行目の `$schema` は knowledge の raw の URL を指す |
| 設計書の検査 | 参照先の knowledge のスキーマの検査で出る違反を、設計書の側で修正する | `check_project` で違反が 0 件 |
| `ai-monitor-version.ini` | 削除し、フォルダ構成の設計書の行も削除する | 取り込むコピーが無くなるため |
| 配布する設定のスキーマ | `templates/prompt.schema.yaml`・`templates/common.schema.yaml` を `schemas/` へ移し、`runtime.py` の定数・`content/prompts/` の 1 行目・設計書・公開ドキュメントを修正する | `src/project_index/schemas/` はサーバーが実行時に参照する原本のため、配置を変えない |
| 既存の機能への影響 | 検索・書き込み・起動の振る舞いは変えない | 起動時のプロンプトの検査が変更後の配置先で通ることを単体テストで確認する |
