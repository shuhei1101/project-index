## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| エラー返却 | `_text_edits` が `text_edits[{n}].field` の違反（項目のパスを解決できない・文字列ではない）を作るとき、`fix` に要件の 3 つの案内を付ける | `message`・`rule`・`path` と違反になる条件は変えない。`_edit_target` の違反が元から `fix` を持つときに、その `fix` を残すか案内と並べるかは設計で決める |
| 共有の項目のパス | `features/documents/fields.py` の `parse_field_path`・`_split_ref_path` の違反の文言は変えない | 他のツール・操作の違反には案内を出さない |
| MOD-80 | 項目の操作の適用の `process` の違反の記載に `text_edits[].field` の `fix` を記載し、`unit_tests` の `#functions[missing].process` の期待値と、文字列ではない項目を指したときの期待値に `fix` を記載する | - |
| IF-6 | `#` で始まる項目のパスの 2 つのフローの期待値に、`text_edits[0].field` の違反の `fix` が 3 つの案内を持つことを記載する | - |
| 既存機能への影響 | `old` の一致の違反と、`@body` の `text_edits`、他の操作の違反は変わらない | - |
