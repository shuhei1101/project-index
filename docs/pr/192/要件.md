# 要件

## 要望

`write_docs` の `text_edits[].field` の違反のうち、次の 2 つに `fix` を付ける。

| 違反 | 今の `fix` |
| --- | --- |
| 項目のパスを解決できない（`_edit_target` の違反を `text_edits[{n}].field` で作り直す箇所） | 作り直しで捨てている |
| 指した項目が文字列ではない（`文字列ではない項目は置き換えられません`） | 無い |

`fix` には次の 3 つを案内する。

- 通る配列が全て `x-key` を持つときは、`#` で始めて `x-key` の値で指す（`#functions[sendForm].summary`）
- `x-key` を持たない配列を 1 つでも通るときは、`#` を付けずに全ての配列を位置で指す（`flows[35].expected[2]`）。`#` のパスでは `x-key` を持たない配列を位置で指せない
- 配列・オブジェクトそのものは `text_edits` ではなく `set`・`add_to`・`remove_from` で書き換える

- 違反になる条件と、エラーの `message`・違反の `rule`・`path` は変えない
- `fix` は `apply.py` の `_text_edits` で付ける。`parse_field_path`・`_split_ref_path` を共有する `features/documents/fields.py` の違反の文言は変えない（`search_docs`・`set`・`add_to`・`remove_from`・`unset` の違反に `text_edits` 向けの案内を出さないため）
- インターフェース定義 IF-6 と、モジュール構成 MOD-80 の `_text_edits` に関わる記載に `fix` を記載する
