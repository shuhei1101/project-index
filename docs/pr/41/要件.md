# 要件

## 要望

書き込む場所がワークツリーのとき、`write_docs`・`delete_docs` は、そのワークツリーの配信元の設定を読み直した配信元で種類と置き場所を参照する。

| 項目 | 終わりの条件 |
| --- | --- |
| 追加した種類 | ワークツリーの `project-index.yaml` にだけある種類を `kind` に指定した `write_docs` の `create` が、その種類の文書を作成する |
| 削除した種類 | ワークツリーの `project-index.yaml` から削除した種類を `kind` に指定した `write_docs` の `create` が `UnknownKindError` を返却し、`available` にその種類が載らない |
| describe との一致 | 同じ `worktree` を指定した `describe` の種類の一覧と、`write_docs` の `UnknownKindError` の `available` が一致する |
| ワークツリーでない書き込み | Git の管理外の配信元への書き込みは、登録済みの配信元の設定のまま参照する |
