## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 書く場所の解決 | `resolve_write_target` は、ワークツリーを決めたら `load_source_at(item, wt)` で読み直した配信元を `Target` に入れる | `write_docs`・`delete_docs` の両方が `resolve_write_target` を使用するため、種類を参照する全ての操作で有効になる |
| エラー返却 | ワークツリーの設定が検証に通らないときは、`load_source_at` の `ValidationFailedError` をそのまま返却する | `describe` と同じ |
| 既存機能への影響 | Git の管理外の配信元（ワークツリーが無い）は登録済みの配信元のまま | - |
