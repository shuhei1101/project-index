## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 文書のマーカー | mdmark v0.11.0 の `mdmark upgrade` を `docs/` へ適用し、`<!-- table: data -->` を `<!-- table: {"kind": "data"} -->` にする。移行の報告に挙がった記載は手で記載し直す | `docs/pr/` は対象外（スコープ外） |
| 生成するマーカー | `<!-- section: closed -->` を `<!-- section: {"open": false} -->`、`<!-- tabs: group=lang -->` を `<!-- tabs: {"group": "lang"} -->` にする | 描いた結果は変わらない |
| 設計書 | IF-18・MOD-41 の記載と期待値を生成するマーカーに合わせる | - |
| テスト | 単体・結合テストの期待値を JSON の記載にする | - |
| 確認 | `mdmark check`（v0.11.0）で `docs/` と生成した文書に `legacy_mark` が出ないことを確かめる | `<!-- embed: x -->` を使う `test_write_docs.py` は、mdmark#479 の後に返る警告が変わるかを確かめる |

### ドキュメント修正
