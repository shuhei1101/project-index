# 要件

## 要望

`write_docs` の 1 ファイル 1 文書の `rename` で、`new_path` を正規化した値が絶対パスか `..` の部分を持つ（配信元の外を指す）ときは、何も書き込まずに `new_path` の違反の `InvalidArgumentError` で断る。

| 指定 | 振る舞い |
| --- | --- |
| `new_path` が配信元の外を指す（`paths` が `**` で始まる種類を含む） | 何も書き込まずに `InvalidArgumentError` で断る。決まりは `new_path（{指定した new_path}）が配信元の外を指します`、直し方は `配信元の直下からのパスを指定してください`（本文のファイルの `rename` と同じ文言） |
| `new_path` が配信元の中を指す | 今と同じく `paths`・`exclude`・既にあるファイルを照合して移す |

- 配信元の外を指すかの確認は、`paths`・`exclude` の照合より先にする
- 判定は #294 の `requested_document_path` と同じもの（正規化した値の絶対パス・`..` の部分）を使い回す
- `new_path` を省いて `new_id` から移し先を決める `rename`、本文のファイルの `rename`、`create` の振る舞いは変えない
