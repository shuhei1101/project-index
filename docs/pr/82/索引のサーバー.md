## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 書き込みの打ち切り | `write_docs`・`delete_docs` の処理に打ち切りの合図と期限を指定し、作業ツリーのファイルを置き換える直前に確認する。呼び出しが取り消された・期限を過ぎたときは書き込まずに時間切れのエラーを返却する。置き換えを始めた後は最後まで書き込む | 期限は非機能要件に追加する決定値 |
| 書き込まなかった理由の返却 | 検査の `ScriptError`（`ScriptTimeoutError`・`ScriptFailedError`・`ScriptNotFoundError`）を `ProjectIndexError` の応答へ変換し、制限時間を超えたスクリプトの ID と制限時間を `isError` で返却する。違反で書き込まなかった場合に `Error executing tool` になる経路を、再現する入力を作って特定する | 原因は設計の工程で確定する |
| ワークツリーを指定した読み取りの待ち | `wait_for` に上限を設け、上限を過ぎたら読み込み中である旨を返却する。作った直後のワークツリーで全ての行の読み込みを待つ経路（`_target_rows` の「該当する行が無ければ全ての行」）と、git の実行の待ちのどちらで時間を消費しているかを計測して特定する | 原因は設計の工程で確定する |
| 非機能要件 | 書き込みと読み取りが応答を返却するまでの上限を、Claude Code の MCP のツールの呼び出しの時間切れから逆算して追加する | NFR-9 と同じ外部の制約 |
