# 要件

## 要望

| 事象 | 終了の条件 |
| --- | --- |
| `write_docs` が時間切れの応答の後も書き込む | 時間切れにしたクライアントへの応答と書き込みの成否が一致する（打ち切るなら書き込まない、書き込むならクライアントの時間切れの前に応答を返却する） |
| 書き込まなかった理由が返却されない | 検査のスクリプトが制限時間（`script_timeout_sec`）を超えた場合と違反で書き込まなかった場合に、`Error executing tool` ではなく、制限時間を超えたスクリプトか違反の内容を `isError` の応答で返却する |
| `worktree` を指定した `search_docs` が時間切れになる | 作った直後のワークツリーを指定した `search_docs`（`view: ids`・`summary`・`full`）が、クライアントの時間切れの前に結果を返却する。ワークツリーの読み込みが上限までに終了しないときは、読み込み中である旨を返却する |

応答を返却するまでの上限は、Claude Code の MCP のツールの呼び出しの時間切れから逆算し、非機能要件に決定値として記載する。
