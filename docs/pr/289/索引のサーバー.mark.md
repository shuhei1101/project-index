## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 稼働中のプロセスの commit | 起動した時点のクローンの HEAD を読み込んだ時点の値として持つ | `RUNNING_VERSION` と同じく、更新の後も変わらない |
| `update` の判定 | `git pull --ff-only` の後のクローンの HEAD を、稼働中のプロセスの起動した commit と比べ、違えば `uv sync`・`migrate --plan` を実行して起動し直す | 応答の表し方は `未確定`（[要件](./要件.mark.md)） |
| `status` | 稼働中のプロセスの起動した commit を返却する | 反映作業の確認方法の観測値にする |
| 既存の振る舞い | 起動した commit とクローンの HEAD が同じで上流に新しい commit も無いとき、`update_failed`・移し替えが要るときの振る舞いは変えない | 破壊的変更なし |
| テスト | クローンが既に最新で稼働中のプロセスが更新前の commit のときに起動し直すこと、`status` が起動した commit を返却することを確認する | 単体と結合 |
