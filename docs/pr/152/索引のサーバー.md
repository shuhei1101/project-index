## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| ID の重なりの検出 | `check_sync` が `LoadResult.problems` の `reason: duplicate_id` を、除外した文書と先の文書のパスと ID の組で 1 件ずつ返却する | 別の行が同じファイルの重なりに数えた同じファイルを文書にするときは数えない |
| `check_project` | 索引の同期の件数・内訳の種類に ID の重なりを追加する | ID の重なりの無い配信元は件数 0 |
| 起動時の警告 | `log_source_check` が ID の重なりを 1 行の警告に記載する | 既存の同期のずれと同じ書式 |
| `status`・`describe` の警告 | `status` の同期の件数と引数なしの `describe` の警告に ID の重なりを追加する | 既存の同期のずれと同じく `SyncReport` から作る |
| 既存機能への影響 | 重なった文書を配信から除外する振る舞いと、既存の同期のずれの検出は変えない | - |
