# 要件

## 要望

- リポジトリの直下の `dev-docs.yaml` を、中身を変えずに `project-index.yaml` へ改名する（`git mv` で履歴を保つ）
- 改名した後、リポジトリの直下に `dev-docs.yaml` が無く、`project-index.yaml` だけがある
- 端末の設定（`~/.config/dev-docs/settings.yaml`）の配信元 `project-index` の `config` を、develop の worktree の `project-index.yaml` へ直す（反映作業）
- 直した後、配信元 `project-index` の文書を改名する前と同じく検索できる
