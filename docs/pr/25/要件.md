# 要件

## 要望

dev-docs から移した処理（`src/`・`tests/`・`plugins/project-index/`）の lint の違反を、振る舞いを変えずに解消し、ベースラインを除外する。

| 検査 | 除外するベースライン（develop の [c19c617](https://github.com/shuhei1101/project-index/commit/c19c617) の時点） | 終わりの条件 |
| --- | --- | --- |
| ruff | `# noqa` 110 行（`src/` 107・`plugins/project-index/hooks/` 3。規則ごとに `ANN401` 65・`S101` 16・`C901` 15・`DTZ011` 5・`S603` 4・`S608` 2・`N818` 2・`BLE001` 2・`S701`・`S606`・`S310`・`PT018` 各 1） | スコープ外の行の `# noqa` を除いて 0 件で、`uv run ruff check .`・`uv run ruff format --check .` が終了コード 0 |
| pyright（strict） | 47 ファイルの先頭の `# pyright: reportUnknown...=warning` の指定（`src/` 33・`tests/` 12・`plugins/project-index/hooks/` 2） | 指定が 0 件で、`uv run pyright` が error・warning とも 0 件 |
| complexipy | `complexipy-snapshot.json`（29 ファイル・41 関数） | ファイルを削除し、`uv run complexipy src tests` が `max-complexity-allowed` の 15 のまま終了コード 0 |

- 単体テスト（`uv run pytest tests/unit/`）と結合テスト（`uv run pytest tests/integration/`）が、テストの期待値を変えずに全 pass する
- MCP のツール・読み取り API・端末の設定の API・コマンドの入出力とエラーの文言を変えない

## 変更箇所の由来

| 対象箇所 | commit | 目的 | 変更回数 | 影響 |
| --- | --- | --- | --- | --- |
| `# noqa`・`# pyright:` の指定・`complexipy-snapshot.json` | [c19c617](https://github.com/shuhei1101/project-index/commit/c19c617)（`dev-docs の文書の MCP・管理の MCP・配信元の読み込みとプラグインを移し、… (#15)`） | dev-docs から移した処理の既存の違反をベースラインにし、新しい違反だけを失敗にする。規約『設計原則』の「既存の Python のリポジトリは warn から始める」に従った暫定 | 1 回 | 違反を解消してから除外するため、新しい違反を失敗にする目的は壊さない |
