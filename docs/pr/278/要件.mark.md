# 要件

## 要望

`project-index prompt-doc` の描画を、aituber の `build_messages` と同じ規則にする。

| 要件 | 終了の条件 |
| --- | --- |
| `x-each` の繰り返し | `x-each: {var, as}` を持つ部品を、`var` の配列の要素ごとに、`as` の名前で要素を指定して描画する。連続する同じ `var` の `x-each` の部品は 1 つのまとまりにし、要素ごとにまとまりの部品を並び順に描画する。`when` は要素ごとに評価する。配列が空か無いときは描画しない |
| メッセージの区切り | `kind: llm` の例の組は、部品を並び順に描画し、連続する同じロールの部品を `LLM_PART_SEPARATOR` でつないで 1 通のメッセージにする（`ROLES` の順に並べ替えない）。`history` が 2 組の `generate-lines.yaml` 相当の例で、`system`・`user`・`assistant`・`user`・`assistant`・`user` の順のメッセージが出る |
| 描画して空の部品 | 描画した本文が空の部品はメッセージに追加しない |
| テンプレートのセクション | `x-each` の部品のセクションに `x-each` のバッジ（`var` と `as`）を出し、本文の `{{ as の変数 }}` に `{var}[]` の定義のツールチップを付ける |
| 使用しなかった部品 | 要素ごとに `when` が偽になった部品も、使用しなかった部品として出す（要素が 1 つでも描画した部品は出さない） |
| ロールを持たない部品 | `kind: llm` では aituber と同じく `user` として扱う |
