## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 部品のモデル | `PromptPart` に `x-each`（`var`・`as`）を受け取るキーを追加する | `as` は Python の予約語のため別名で受け取る |
| 繰り返し | 連続する同じ `var` の `x-each` の部品をまとめ、`var` の要素ごとにまとまりを描画する。要素は `as` の名前で、`when` と本文に指定する | 要素の値は `{var}[]` のパス付きの値にする |
| メッセージ | `kind: llm` は並び順のまま、連続する同じロールの部品を 1 通にまとめる。描画して空の部品は追加しない | ロールを持たない部品は `user` として扱う |
| テンプレートのセクション | `x-each` のバッジを出し、`as` の変数を `{var}[]` のパスに読み替えてツールチップを付ける | `{% for %}` のループの変数と同じ読み替え |
| 既存機能への影響 | `x-each` もロールの並びも持たないプロンプトの描画結果は変わらない | 既存の単体・結合テストを回帰で回す |
