## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 外部ライブラリの設計書 | LIB-7 の `version.current` を `develop`、`source` を `@develop` にし、`pinning` を「既定で develop の最新。タグか commit の SHA で固定できる」記載にする | - |
| 管理の MCP の `update` | `uv sync` の後、`PATH` に `mdmark` があれば `npm install -g github:shuhei1101/mdmark#{mdmark_ref}` で入れ直し、結果を応答に入れる。失敗しても更新と再起動は続ける | - |
| 公開ドキュメント | ガイドの mdmark の CLI の入れ方を `#develop` にし、固定するときの記載方法を添える | - |
| バージョンの固定の設定 | 端末の設定のキー `mdmark_ref`（既定 `develop`）で、入れる mdmark の参照を決める | - |
