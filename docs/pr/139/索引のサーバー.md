## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| run の参照の待ち | `run_id` を取った後、`gh api "repos/{owner}/{repo}/actions/runs/$run_id"` が成功するまで 1 秒おきに試し、10 回で参照できなければ `実行 {run_id} を 10 秒参照できません` を標準エラーに出して終了コード 1 で終える | claude-balancer の TP-275-1 の `run_runner` と同じ待ち方。PR #121 の 404 は起動の直後の未反映で、同じ run は後で参照できた |
| 参照できた後の流れ | `gh run watch` 以降は今のコマンドのまま | - |
| 対象の層 | `location` が `runner` の TL-1・TL-2 | TL-6（lint）は `local` のため対象外 |

## テスト結果

### ドキュメント修正

| `tests/unit/` | 全実行 | 実行のみ | ✅ | 1131 テスト pass（ランナー。TL-1 の `run_runner` の終了コード 0）<br>`テスト結果/20261117181748_c86bd34_単体テスト.log` |

TL-2 の `run_runner` は、同じ待ちのコマンドを `run_id` の後に加えただけで、結合テストを回す範囲が無いため実行していない。
