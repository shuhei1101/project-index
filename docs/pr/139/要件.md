# 要件

## 要望

- TP-1 の TL-1（単体テスト）・TL-2（結合テスト）の `run_runner` で、`gh workflow run` が返却した run を API で参照できるまで待ってから `gh run watch` を呼ぶ
- 上限の時間内に参照できない場合は、run の ID を添えたメッセージを標準エラーに出して失敗で終える
- 参照できた後の流れ（`gh run watch` の終了コードを合否にし、成果物 `test-log` のログか失敗したジョブのログを出す）は変えない

## 変更箇所の由来

| 対象箇所 | commit | 目的 | 変更回数 | 影響 |
| --- | --- | --- | --- | --- |
| `docs/test-procedure/TP-1.yaml` の TL-1・TL-2 の `run_runner` | [bd8a101](https://github.com/shuhei1101/project-index/commit/bd8a10107875ed36a301960c411c707043dc6cab)（`テスト実行方法の層ごとに実行場所を決め、ランナーで回せる層を GitHub Actions の workflow で回す (#116)`） | workflow を `workflow_dispatch` で起動して終わるまで待ち、失敗したときもログを取得してから失敗で終える 1 コマンドとして配置した。起動の直後に run を参照できない場合は考慮していない | 1 回 | 待ちを `gh run watch` の前に追加する修正は、この目的を壊さない |
