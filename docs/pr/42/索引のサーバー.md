## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| スキーマの参照の解決 | 最上位の `$defs` は参照先として残したまま、その中の相対パスの `$ref` を参照先の中身で解決する。循環する参照は `#/$defs/...` のまま残す | knowledge の `layout.schema.yaml` を手元で解決し、相対パスの `$ref` が残らないことを確認する |
| エラー返却 | スキーマの参照を解決できない場合、解決できなかった `$ref` とスキーマのファイルを決まりにした違反にする。`search_docs` は `notes` で知らせて文書を返却し、`write_docs` は `ValidationFailedError` で返却する | 新しいエラーは追加しない（[IF-2](https://github.com/shuhei1101/project-index/blob/245e402/docs/interface/IF-2.yaml)・[IF-6](https://github.com/shuhei1101/project-index/blob/245e402/docs/interface/IF-6.yaml)） |
| 既存機能への影響 | `$defs` に相対パスの `$ref` を持たないスキーマの解決結果は変えない | 既存の単体テスト・結合テストで回帰を確認する |
