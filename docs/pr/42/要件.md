# 要件

## 要望

- 種類のスキーマの `$defs` の中にある相対パスの `$ref`（`$defs` の中の循環する参照を経由した先を含む）を、スキーマのファイルのフォルダを基準に解決する
  - knowledge の `LAY-72-1` を `search_docs`（`filter: id eq LAY-72-1`）で取得でき、`write_docs`（`op: update`・`text_edits`・`dry_run: true`）で部分更新できる
- 参照先のファイルが無い・YAML として読み込めないなど、スキーマの参照を解決できないまま検査・Markdown のキーの抽出・違反の説明の付与に進む場合、`search_docs`・`write_docs` は `isError: true` のツール結果で、解決できなかった `$ref` とスキーマのファイルの分かるエラーを返却する
  - `ProjectIndexError` 以外の例外として送出しない（`Error executing tool ...` だけで止まらない）
- 単体テストで、`$defs` の中の相対パスの `$ref` と循環する参照を併せ持つスキーマを再現する
