## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 改名の本文のファイルの参照 | 同じ配信元の `records`・`body_file` の行の文書の本文のファイルに、YAML の項目の (3) `id:{旧 ID}` と (4) Markdown のリンクの先の規則を適用する。相対パスは本文のファイルのフォルダから解く | `id:{旧 ID}` と Markdown のリンクの先だけ |
| 一括置換の本文のファイル | `filter` に該当する文書の本文のファイルの `old` を `new` にする。`fields` の `@body` で本文のファイルを指す | `fields` を省くと本文のファイルも対象 |
| 本文のファイルの検査 | 書き換えた本文のファイルは、今までどおりスキーマ・`validators[]`・mdmark の点検に通さない。本文だけが変わった文書もバージョンと差分（`@@ {本文のファイルのパス}`）を返す | 既存の「本文のファイルの検査」「本文のファイルを持つ文書のバージョン」の制約を使う |
| 本文のファイルの書き込み | 要素の YAML と同じく全ての検査に通ってから一時ファイルを経由して置き換える | 既存の「本文のファイルの書き込み」の制約を使う |
| 共有する本文のファイル | 同じ本文のファイルを複数の要素が指すときは、1 回だけ書き換える | 件数と差分を二重に数えない |
| 既存機能への影響 | 本文のファイルを持たない文書の `rename`・`replace_text` と、`create`・`update`・`replace`・`delete_docs` の入出力は変えない | - |
| ほかの配信元・配信の範囲の外のファイル | 対象外のまま | スコープ外 |
