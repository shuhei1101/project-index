# 要件

## 要望

`write_docs` の `create` で新しい文書の配置先を決められないときの修正案（違反の `fix`）のうち、`records` を持たない行で `paths` の先頭のファイル名の `*` を 1 つ ID に置き換えた後もファイル名に glob（`*`・`?`・`[`）が残るときの修正案を、ファイル名の glob を `*` の 1 つだけにする旨へ変える。

| 文書の行 | 配置先を決められない条件 | 修正案 |
| --- | --- | --- |
| `records` を持つ | `paths` が空か、先頭が glob を含む | `documents[].paths の先頭を glob を含まない 1 つのファイルにしてください`（今のまま） |
| `records` を持たない | `paths` の先頭が glob を含まない | `documents[].paths の先頭を glob にしてください`（今のまま） |
| `records` を持たない | ファイル名の `*` を 1 つ ID に置き換えた後もファイル名に glob が残る（例: `docs/*-*.yaml`・`docs/doc?.yaml`・`docs/**`） | `documents[].paths の先頭のファイル名の glob を * の 1 つだけにしてください` |

- エラーの `message`・違反の `rule`・`path`（`operations[{i}].kind`）と、エラーになる条件は変えない
- モジュール構成 MOD-83 の `new_document_path` の `process` の修正案の記載と `unit_tests` に、ファイル名に glob が残るときを追加する
