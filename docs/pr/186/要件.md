# 要件

## 要望

テスト実行方法 TP-1 の TL-1（単体テスト）・TL-2（結合テスト）の、ランナーを使用せずに手元で回すコマンド（`run_all`・`run_one.command`）を、`uv run pytest` から `uv run --with-editable {observability のクローン} pytest` に書き換える。

- `pyproject.toml`・`uv.lock`・`run_runner`・`.github/workflows/test.yml`・各層の `location` は変えない
- `{observability のクローン}` の置き換え方と、observability のクローンが無い環境では `uv run pytest` で回してよいことを TP-1 に書く
- 書き換えた TL-1 の `run_all` を手元で 1 回回し、Prometheus に `repository="project-index"` の `test_session_duration_seconds` が届くことを確かめる
