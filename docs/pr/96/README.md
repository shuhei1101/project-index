# AI Monitor v0.5.0 の配布物へ追従する

## 概要

取り込んだ AI Monitor のバージョンの記録を v0.4.0 から v0.5.0 へ上げ、v0.5.0 で変わった規約・テンプレート・判定フローチャートと配布先の反映作業にこのリポジトリを合わせる。

## 背景

[Issue #95](https://github.com/shuhei1101/project-index/issues/95) は、AI Monitor が v0.5.0 のバージョン上げで配った追従 Issue。
`ai-monitor-version.ini` は v0.4.0 のまま。
配布先の反映作業は [ai-monitor#3462](https://github.com/shuhei1101/ai-monitor/pull/3462) の『配布先の mdmark の設定へのノードの種類の記載』の 1 件で、直下に `mdmark.config.yaml` は無い。
