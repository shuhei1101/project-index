## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 文書の一覧（IF-24） | 各要素に、文書のストアが持つ `version` を常に加え、`value` は `values=true` のときだけ文書の値を入れる（それ以外は `null`） | - |
| 文書の取得（IF-25） | 文書の ID を指すクエリを加え、`path` のファイルの中の文書のうち ID が一致する文書を返す。一致しなければ 404（`missing` が `doc`） | 指さないときの引き方は今と同じ |
| 語での検索（IF-28） | `items[]` に文書の ID と文書のファイルのパスを加え、文書の取得へ同じ組で渡せるようにする | - |
| 配信元の設定の取得（IF-23） | 応答に配信元の設定の `diff` を加え、クエリで求めたときだけ `documents[]` の行ごとに `resolve_schema_refs` で解いた種類のスキーマを加える | 循環する参照は `$ref` のまま残し、最上位の `$defs` を残す |
| `records` の行のスキーマ | 要素 1 つのスキーマに、ファイル全体のスキーマの最上位の `$defs` を加える。文書の取得（IF-25）の `schema` と配信元の設定の `schemas` の両方に効く | - |
| 既存機能への影響 | 既存の応答のキーは残して足すだけにする | 破壊的変更なし |
| 性能 | 値とバージョンは文書のストアが読み込み済みの文書から返し、文書ごとにファイルを読み直さない | - |
