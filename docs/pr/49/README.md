# 読み取り API の文書の一覧に値とバージョンを、文書の取得に行の要素の指定を、検索の結果に文書の ID を、配信元の設定に diff と解いたスキーマを追加する

## 概要

dev-docs の画面のサーバーが、読み取り API だけで画面の `nav` の `auto`・差分のマーカー・管理用の YAML の行の文書の表示・検索の結果の遷移・絞り込みのフィールドの一覧を組み立てられるようにする。

## 背景

[Issue #46](https://github.com/shuhei1101/project-index/issues/46) の要望。
[shuhei1101/dev-docs#183](https://github.com/shuhei1101/dev-docs/pull/183) で、画面のサーバーの付け替え口の接続先をモックから読み取り API（[#14](https://github.com/shuhei1101/project-index/issues/14)・[#15](https://github.com/shuhei1101/project-index/issues/15)）へ変える。
今の読み取り API では、文書の一覧（IF-24）が値とバージョンを返さず、文書の取得（IF-25）を文書の数だけ呼ぶと 1 回の画面の表示に数百回の要求になる。
文書の取得（IF-25）と語での検索（IF-28）は管理用の YAML の `records` の行の文書を 1 つに選べず、配信元の設定の取得（IF-23）は `diff` と `$ref` を解いた種類のスキーマを返さない。
