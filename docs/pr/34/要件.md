# 要件

## 要望

`project-index.yaml` の `documents[]` の `files_guide` の行の `exclude` から `"*.yml"` を除外する。

| 項目 | 終わりの条件 |
| --- | --- |
| 配信元の設定 | `files_guide` の行の `exclude` が、`paths` の `docs/guide/files.yml` のファイル名に該当するパターンを持たない |
| 配信 | `search_docs`（`source: project-index`・`group_by: kind`）で、`files_guide` の文書が `docs/guide/files.yml` の `files` の行の数だけ返る |
| 検査 | `check_project` が、`docs/guide/` の配下の `index.yaml` を索引に無いファイルとして数えない（`"*.yaml"` は残す） |

`documents[]` の他の行で、`paths` のファイル名が同じ行の `exclude` に該当する行は無い（origin/develop の `project-index.yaml` で照合した）。

## 変更箇所の由来

| 対象箇所 | commit | 目的 | 変更回数 | 影響 |
| --- | --- | --- | --- | --- |
| `project-index.yaml` の `files_guide` の行の `exclude` | [c647d53](https://github.com/shuhei1101/project-index/commit/c647d53)（`dev/ を廃止して文書を docs/ 1 つにまとめ、ai-monitor#3307 と同じ構成へ移す (#13)`） | 文書を `docs/` へまとめたときに、`docs/guide/` の配下で Markdown でないファイルを索引に無いファイルとして数えないために置いた。`files.yml` 自身が該当することは考慮されていない | 1 回 | 管理用の YAML 自身は索引に無いファイルの数から常に除かれるため、`"*.yml"` を除外しても目的を壊さない |
