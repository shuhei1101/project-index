# 要件

## 要望

project-index 自身の配信元に直下の管理用の YAML を追加し、索引の同期の 3 つの件数を 0 に保つ。

- 直下の `project-index.yaml` の `documents[]` に、直下の `files.yaml` を指す行（`records: files`・`body_file: path`）を追加する
- 直下の `files.yaml` に、直下のファイル 10 件（`.gitignore`・`.python-version`・`CLAUDE.md`・`README.md`・`mdmark.config.yaml`・`project-index.yaml`・`pyproject.toml`・`rules.yaml`・`uv.lock`・`version.ini`）と `docs/` 直下の 2 件（`docs/README.md`・`docs/_config.yml`）を記載する
- PR ドキュメント（`docs/pr/**`）は、追加する行の `exclude` のパスで外す
- 終わりの条件: 管理の MCP の `check_project` と `describe` の警告で、追加した行の「管理用の YAML に無いファイル」「ファイルが無い行」「`metadata` の列が無い文書」がどれも 0 件
