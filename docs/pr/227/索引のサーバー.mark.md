| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 使える項目 | `_walk` で、`allOf`・`anyOf`・`oneOf` の各要素を同じパスの接頭辞でたどる | - |
| 使える項目 | `$ref` のまま残った `#/$defs/...` は、最上位のスキーマの `$defs` から参照先を参照してたどり、同じ定義へ戻った時点で止める | インターフェース定義設計で A に決めた |
| 既存機能への影響 | 今使用できる項目と型、項目の値の取得（`field_values`）は変えない | - |
