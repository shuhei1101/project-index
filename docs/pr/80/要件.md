# 要件

## 要望

- 直下の `ai-monitor-version.ini` を `v0.3.0` から `v0.4.0` へ上げる
- AI Monitor の `v0.3.0..v0.4.0` で変わった規約・テンプレート・判定フローチャート・チェックシートを読み直し、従っていない成果物を直す
- MCP `update_plugins` でプラグインを取り直し、AI Monitor の `settings.yaml` の設定スキーマと `agents[].mcp_tools` を見直す
- 配布先の反映作業 7 件（[反映作業/index.yaml](./反映作業/index.yaml)）の実行スクリプトをこのリポジトリへ流し、全ての作業で書き換えが起きないこと（`skipped`）か、整っていること（`ok`）を確かめて記録する

反映作業『配布先の dev-docs への移行』は、改名後の `project-index.yaml` で整っていることを確認方法（`describe()` の一覧に権限 `write` で出る）で確かめて記録する。
dry-run の `dev-docs.yaml: failed`・`配信元の登録: failed` は、スクリプトが改名前の `dev-docs.yaml` を探すことによるもので、配布元のスクリプトは書き換えない。
