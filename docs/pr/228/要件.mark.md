# 要件

## 要望

`write_docs` の `create` と本文のファイルを持たない要素への `update`・`replace` が `@body` を渡さず既にあるファイルを指すとき、そのファイルが次のどれかなら、`body_file` の列の違反にして要素も本文のファイルも書き込まない。

- 配信元の設定のファイル（`project-index.yaml` と、端末の設定の `sources[].config` に並べた配信元の中のファイル）
- `validators[]`・`converters[]`・`generators[]` のスクリプトのファイル
- 有効な行の `paths` に該当し `exclude[]` に該当するファイル

違反の決まりには、どの種類のファイルかを含める。
今の断る対象（配信元のいずれかの文書のファイル）と、それ以外の既にあるファイルの取り込みの結果は変えない。

断る対象は、配信元の設定・スクリプト・`exclude[]` に該当するファイルを、今の断る対象に加えて決める（取り込めるファイルを管理用の YAML のフォルダの中に限る案は、フォルダの中に配置したスクリプト・`exclude[]` のファイルを断れず、配信元の直下の管理用の YAML では全てのファイルがフォルダの中になるため採らない）。
