# write_docs の既にある本文のファイルの取り込みで、文書でない配信元のファイルを断る

## 概要

`write_docs` で既にあるファイルを本文のファイルとして取り込むとき、配信元の設定・スクリプト・`exclude[]` に該当するファイルを取り込めないようにする。

## 背景

[Issue #226](https://github.com/shuhei1101/project-index/issues/226) の要望。[PR #220](https://github.com/shuhei1101/project-index/pull/220)（起点 [Issue #218](https://github.com/shuhei1101/project-index/issues/218)）で、`@body` を渡さず既にあるファイルを指す `create`・`update`・`replace` が、そのファイルを本文のファイルとして取り込めるようになった。
断る対象は配信元のいずれかの文書のファイルまでで、文書でない配信元のファイルは取り込めてしまう。
取り込んだ要素を `delete_docs` で消すと本文のファイルも削除され、`rename` で移ると本文のファイルも移るため、これらのファイルが壊れる。
