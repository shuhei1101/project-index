## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 断る対象 | 既にあるファイルの取り込みで、配信元の設定のファイル・`validators[]`・`converters[]`・`generators[]` のスクリプトのファイル・有効な行の `paths` に該当し `exclude[]` に該当するファイル・有効な行の `schema` が文字列のときに指すスキーマのファイルを `body_file` の列の違反にする | スクリプトのファイルは、`run` の要素が配信元のフォルダからのパスとして指すファイル |
| 違反の決まり | どの種類のファイル（配信元の設定・スクリプト・除外したファイル・スキーマ）かを含める。直し方は今どおり、どの文書のファイルでもないパスを指定すること | - |
| 既存の操作への影響 | 配信元のいずれかの文書のファイルを断る判定と、それ以外の既にあるファイルの取り込み・`@body` を渡す作成の結果は変えない | - |
