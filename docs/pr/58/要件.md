# 要件

## 要望

- 種類のスキーマから参照した別のファイルの中で循環する `#/$defs/...` の参照を、そのファイルの `$defs` の定義を指したまま検査に適用する
- 種類のスキーマ自身の中で循環する `#/$defs/...` の参照は、今のとおり種類のスキーマの最上位の `$defs` を指したまま検査に適用する
- 単体テストで、別のファイルの中で循環する参照を持ち、種類のスキーマの最上位の `$defs` に同じ名前の別の定義があるスキーマと、同じ名前が無いスキーマを再現する
