## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 別のファイルの中の循環 | 参照先が種類のスキーマと別のファイルで循環する `$ref` は、参照先の定義を解いた中身を解いた後のスキーマの最上位の `$defs` へ、種類のスキーマの定義と重ならない名前で加え、`$ref` をその名前の `#/$defs/...` に書き換える | 加える名前の付け方はモジュール構成設計で決める |
| 種類のスキーマの中の循環 | 今のとおり `#/$defs/...` のまま残す | - |
| 警告 | 循環する参照を残した・書き換えたときの `[warning]` は今の条件のまま出す | - |
| 応答の `schema`・`schemas` | 最上位の `$defs` に加えた定義も、`records` の行の `$defs` と配信元の設定の取得の `schemas` へ今の作りのまま届く | IF-23 の notes を追加した定義に合わせて修正するかはインターフェース定義設計で決める |
