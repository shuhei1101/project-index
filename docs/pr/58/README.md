# スキーマの参照先の別のファイルの中で循環する $defs の参照を、参照元のファイルの定義へ向けて検査する

## 概要

種類のスキーマが参照する別のファイルの中で `#/$defs/...` が循環していても、エージェントが `search_docs`・`write_docs` でその種類の文書を、参照元のファイルの定義どおりに検査できるようになる。

## 背景

[#44](https://github.com/shuhei1101/project-index/issues/44) の不具合（[#42](https://github.com/shuhei1101/project-index/pull/42) の作業中に見つけたもの）。

スキーマの参照の解決（`features/documents/schema.py` の `resolve_schema_refs`）は、循環する `$ref` を解かずにそのまま残す。
参照先が別のファイル（`common.schema.yaml` など）で、そのファイルの中で循環する `#/$defs/x` は、どのファイルの `$defs` かを持たない `$ref` として解いた後のスキーマに入る。
解いた後のスキーマの最上位の `$defs` は種類のスキーマのものだけのため、jsonschema はこの `$ref` を種類のスキーマの `$defs` に当て、参照先を取り違えるか、同じ名前が無ければ「スキーマの参照 {ref} を解決できません（{スキーマのファイル}）」の違反になる。
