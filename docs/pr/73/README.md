# フォルダ構成の設計書（layout）を作成し、今のフォルダ構成をレビューの観点で確認する

## 概要

knowledge のテンプレート『フォルダ構成』の書式で、このリポジトリのフォルダ構成の設計書を作成し、規約『フォルダ構成の切り方とレビュー』のレビューの観点で今のフォルダ構成を確認する。

## 背景

[Issue #7](https://github.com/shuhei1101/project-index/issues/7) の要望。
このリポジトリにはフォルダ構成の設計書が無く、フォルダ構成の問題をレビューで洗い出せない。
テンプレートは [shuhei1101/knowledge#219](https://github.com/shuhei1101/knowledge/issues/219) で、設計書の検査を knowledge のスキーマの参照に切り替える変更は [shuhei1101/ai-monitor#3188](https://github.com/shuhei1101/ai-monitor/issues/3188) で入った。
