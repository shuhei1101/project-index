# 要件

## 要望

[PR #15](https://github.com/shuhei1101/project-index/pull/15) で移した文書（`docs/` の設計書と `docs/guide/` の公開ドキュメント。`docs/pr/` を除く）を、[shuhei1101/dev-docs#95](https://github.com/shuhei1101/dev-docs/issues/95) の手順（移行の手順 A-5）で次の状態にする。
文書が定める内容（入出力・制約・シナリオの流れ・期待値）は変えない。

| 工程 | 終わりの条件 |
| --- | --- |
| 図の置き換え | Mermaid のブロック（`docs/interface/` 32・`docs/scenario/` 12・`docs/guide/` 3 ファイル）を mdmark の図の記法にし、`mdmark check` を通る。図の中のラベルに内部の ID を出さない |
| 文を表へ | 同じ属性を持つ項目が 2 件以上ある文・箇条書きと、`**キー**: 値` が 3 つ以上並ぶものが表になっている |
| 文の削除と AI Slop の修正 | 見出し・図・表で分かることの繰り返し、既出の言い直し、理由の説明、当たり前の注意が無い。残す文が規約『文章の書き方』の確認表と AI slop の単語の対応表に当たらない |
| `description` | 全ての文書の `description`（設計書の `lead`）が「何を定め、どんなときに参照するか」の 1 文になっている |
| 本文に出さないもの | 本文に生の文字の Issue 番号・文書のパスが無く、タイトル付きのリンクになっている |
| dev-docs#74 の残り | 設計書の本文に、他の設計書をパスで指す参照が無い（`{ID}#{項目のパス}` の形になっている） |
| 検査 | `write_docs` の検査と `mdmark check` を通り、画面で描いた図が重ならずに読める |

Mermaid の `sequenceDiagram`（`flow`・`steps` のキー）の置き換え先は、Mermaid のブロックを残し、mdmark の図 map のマーカーで囲む（A-5 の手順 2 のとおり）。
