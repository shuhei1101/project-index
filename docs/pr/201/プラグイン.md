## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 手順と基準の移し先 | SKILL.md の `## 手順` と `## 開発中の使用方法` の中身を `docs/guide/` の手順のページと基準のページへ移す。手順の中身は変えない | 置き場所は判定フローチャート『ドキュメント配置判定』で `docs/guide/`（使い方）、形式は Markdown（既存のガイドと同じ `files.yml` の行） |
| SKILL.md | 引数・質問の方法・管理の MCP のツール名と、手順のページを文書の MCP で取得して上から進めることだけを残す | 呼び方・`argument-hint` は変えない |
| 文書の MCP につながらないとき | `/project-index:global-setup` を案内して止まり、何も書き換えない | SC-5 の異常シナリオ（文書の MCP につながらない） |
| 手順のページが返らないとき（該当 0 件か、配信元 project-index が無いエラー `UnknownSourceError`） | クローンが更新前のバージョンなので、どちらも管理の MCP の `update` を案内して止まり、何も書き換えない | SC-5 の異常シナリオ（手順のページを取得できない） |
