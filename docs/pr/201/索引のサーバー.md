## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 手順のページの取得 | 端末の設定に配信元 `project-index` が無いときは、クローンの `project-index.yaml` の `docs/guide/` の行だけを組み込みの配信元 `project-index` として読み込み、作業範囲の外（参考）として `search_docs`・`describe`（`outside_scope: true`）で返却する | 書き込み（`write_docs`・`delete_docs`）は読み取りだけの配信元と同じエラーにする |
| 登録済みの端末 | 端末の設定に配信元 `project-index` の行がある端末では、その行の配信を優先し、同じページを 2 つの配信元から返さない | - |
| 文書の MCP の instructions | 配信元の文書を足した・書き換えたときに、手順と基準のページをどの引数で取得するかを伝える | - |
| 既存機能への影響 | 端末の設定のキーとその既定値・`check_project` の結果は変えない | 組み込みの配信元にキーが要ると分かったら、データ設計の工程を戻す |
