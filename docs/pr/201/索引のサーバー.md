## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 手順のページの取得 | 端末の設定に配信元 `project-index` が無いときは、クローンの `project-index.yaml` の `docs/guide/` の行だけを組み込みの配信元 `project-index` として読み込み、作業範囲の外（参考）として `search_docs`・`describe`（`outside_scope: true`）で返却する | 書き込み（`write_docs`・`delete_docs`）は読み取りだけの配信元と同じエラーにする。行の `schema` はクローンの `templates/files.schema.yaml` に差し替え、knowledge の配信元を要さない（[IF-15](../../interface/IF-15.yaml) の制約『組み込みの配信元』） |
| 登録済みの端末 | 端末の設定に配信元 `project-index` の行がある端末では、その行の配信を優先し、同じページを 2 つの配信元から返さない | - |
| 登録済みの端末の作業範囲の外 | 端末の設定の project-index の行の `scope.read` に当たらない作業場所からは、`outside_scope: true` で行の配信元を作業範囲の外（参考）として返却する。行に `outside_read: false` を記載した端末では取得できないことを受け入れる | 利用者が明示的に外部からの参照を断った設定のため、組み込みの配信元で上書きしない |
| 文書の MCP の instructions | 配信元の文書を足した・書き換えたときに、手順と基準のページをどの引数で取得するかを伝える | - |
| 既存機能への影響 | 端末の設定のキーとその既定値・`check_project` の結果は変えない | 組み込みの配信元にキーが要ると分かったら、データ設計の工程を戻す |
