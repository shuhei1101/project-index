## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| ツールの `cwd` の説明 | 文書の MCP の全てのツールの入力の `cwd` に、フックがセッションの作業場所で上書きし指定した値は使わないことと、ワークツリーは `worktree` で指すことを `description` として持たせる | 説明の文はツール間で 1 つの定数を共有する |
| `TargetIsCloneError` のクローン本体のパス | `resolve_write_target` が返すクローン本体のパスを `main_root`（無ければ `repo_root`、それも無ければ `root`）にする | - |
| フック | 上書きを変えない | IF-20 の制約「上書き」の目的（`scope` の外を書き換えさせない）を保つ |
| 書き込み先の解決 | `worktree` を指定したときの動作と、`scope.write` の判定は変えない | - |
| IF-1〜IF-7 | `request` の `cwd` の説明を揃え、IF-6 にツールの説明の期待値と、設定をワークツリーから読む配信元の `TargetIsCloneError` の flow を足す。IF-7 の `TargetIsCloneError` の `notes` も IF-6 と揃える（`delete_docs` も同じ `resolve_write_target` を使うため、flow とテストは IF-6 の 1 件に任せる） | インターフェース定義設計の工程 |
