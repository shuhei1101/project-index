## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| `GET /sources` の応答 | 全ての行の読み込みを待たずに応答し、読み込みが終わっていない配信元を読み込み中として返す | 値の形はインターフェース定義設計で決める |
| 起動の後の行の読み込み | 行を並列に読み込み、読み込みの遅い行がほかの行の読み込みを止めないようにする。待っている要求が指す行を先に読む | 同時に読み込む行の数はモジュール構成設計で導く |
| `status` の `loading` | `GET /sources` の読み込み中の扱いと矛盾しないように揃える | - |
