## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| `GET /sources` の応答 | `include_loading=true` のとき全ての行の読み込みを待たずに応答し、読み込みが終わっていない配信元を `loading` で返す | 渡さない要求は今どおり待ち、`loading` を返さない（dev-docs の画面のサーバーとの互換） |
| 起動の後の行の読み込み | 行を並列に読み込み、読み込みの遅い行がほかの行の読み込みを止めないようにする。待っている要求が指す行を先に読む | 同時に読み込む行の数は 10（非機能要件 NFR-13。`/mnt/c` の 14 件で 58.9 秒→14.5 秒、ext4 は CPU で決まり変わらない） |
| `status` の `loading` | 読み込み中も、読み込み済みの行と `loading` の行を `sources` に並べ、`GET /sources?include_loading=true` に揃える | - |
