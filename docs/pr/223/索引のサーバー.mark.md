## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| `#` で始まる `set` のキー | 最後の区切りの手前までを `resolve_ref_path` と同じく x-key の値・辞書のキーで位置とキーの並びに解き、最後のキーへ値を設定する。最後のキーが無ければ追加し、あればオブジェクトは今の値へマージ・それ以外は置き換える | 最後の区切りが辞書の項目の `[{キー}]` のときはそのキーを最後のキーとして扱い、無ければ追加する。配列の項目の `[{値}]` のときは要素が実在しないと断る |
| 断る条件 | x-key の無い配列・該当する要素の無い値・無い順番・途中の無いキーは、他の操作と同じ文の `InvalidArgumentError` を `set.{キー}` の違反にする | 途中の項目は作らない |
| `#` で始まらない `set` のキー | 結果は変えない。要素の選び方を含むときの違反の文に、`#` で始めて x-key の値で要素を指す書き方を加える | - |
| 共通のキーへの読み替え | `#` で始まる `set` のキーは読み替えない | - |
