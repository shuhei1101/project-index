# 要件

## 要望

| 番号 | 終わりの条件 |
| --- | --- |
| 1 | `set` のキーに `#` で始まる参照の型の項目のパス（`#functions[createParser].usecase`）を指定でき、x-key の値で指した要素に今は無いキーを追加できる。追加で変わる行は、追加したキーの行だけ |
| 2 | 要望 1 のパスの最後のキーが既にあるときは、`#` で始まらない `set` と同じく値を置き換える（オブジェクトの値は今の値へマージする） |
| 3 | x-key の無い配列・該当する要素の無い値・無い順番・途中の無いキーを指す `#` で始まる `set` のキーは、`text_edits`・`add_to`・`remove_from`・`unset` と同じ文の `InvalidArgumentError` で断り、書き込まない |
| 4 | `#` で始まらない `set` のキーに `[]`・`[{キー}]`・`**.` を含めたときの違反の文が、`#` で始めて x-key の値で要素を指す書き方を示す |

- `#` で始まらない `set` のキーの結果（位置で指すパス・途中の項目を作る扱い）は変えない
- `#` で始まる `set` のキーは、`add_to`・`remove_from` と同じく共通のキーへ読み替えない
- 確認方法: Issue の手順（mdmark の `docs/module/MOD-472-211.ts.yaml` の内容と knowledge の `schemas/design/module.schema.yaml` に `set` で `#functions[createParser].usecase` を適用する）と同じ構造の文書で、`usecase` の 1 行だけが増えることを観測する
