## 変更方針

<!-- table: {"kind": "data"} -->

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 項目のパスの記載 | 先頭の `**.` を「どの深さでも」を表す記載として受ける。`**` は先頭に 1 つだけ配置できる | 途中の `**`・2 つ以上の `**` は今と同じ書式の誤り |
| 項目の取得 | `**.{残りのパス}` は、文書の全ての辞書（最上位と、辞書・配列の要素の中）で残りのパスをたどり、たどれた値を 1 つの並びにする。残りのパスが `[]` で終われば要素を平らにつなぐ | どこにもたどれなければ無いときの値を返却する。並びの順は文書の中の出現順 |
| メタデータの解決 | 列名に `**` を含む共通のキーも『項目の取得』で値を取る。`trace_related`・`search_docs`・読み取り API は解決済みの値を参照するため変えない | - |
| 書き込み | 『項目の書き込み』『項目の削除』は `**` を含むパスを断る。`write_docs` の共通のキーの列名への読み替えは、`**` を含む列名に対応づけたキーへの操作を違反にする | 違反の文言はインターフェース定義設計で決める |
| 削除 | `delete_docs` の `on_referenced: unlink` は、参照元の `related` の列が指す配列を『列名の指す配列の取得』で取り、`**.` で始まる列名では最上位と入れ子の全ての配列から行を除く | - |
| 起動・`check_project` の確認 | `metadata` の列の欠けと該当しない `related[].to` は、解決した値で今と同じく数える | `**` の対応でどこにも列が無い文書は、列の欠けに数える |
| 利用者向けのドキュメント | `docs/guide/設定.md` の `documents[].metadata` の行と、`docs/guide/コアコンセプト-文書のメタデータ.md` に記載と例を加える | - |
| 既存機能への影響 | 既存の記載の意味は変えない | 破壊的変更なし |
