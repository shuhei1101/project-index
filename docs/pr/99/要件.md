# 要件

## 要望

配信元の設定の `documents[].metadata` の列名に、文書の中のどの深さの同じ名前の列も集める記載 `**.{列名}` を追加する。
`related: "**.refs[]"` は、最上位の `refs` と、辞書・配列の要素の中にある全ての `refs` の要素を、1 つの並びにまとめて `related` の値にする。

| 対象 | 終わりの条件 |
| --- | --- |
| メタデータの解決 | `**.refs[]` の対応で、最上位と入れ子（`categories[].refs`・`functions[].refs` など）の `refs` の要素が全て `related` の並びに入る。どこにも `refs` が無い文書は `related` を持たない |
| 関連のたどり（`trace_related`） | まとめた `related` の要素の `to` で、最上位と入れ子の両方の関連の相手をたどれる。`type` は今の `related` と同じく `related.types` で確認する |
| 起動・`check_project` の確認 | まとめた `related` の要素の `to` が、今の `related` と同じく「どの文書にも該当しない `related[].to`」の照合に入る |
| 書き込み（`write_docs`） | `**` を含む列名に対応づけた共通のキーへの操作は、書き込む場所を 1 つに決められないため違反で断る。`**` を含む項目のパスへの書き込み・削除も断る |
| 既存の記載 | `meta.summary`・`tags[].name`・`tags[main].name` の記載の意味は変えない |
| 利用者向けのドキュメント | `documents[].metadata` の説明に `**.{列名}` の記載と例を加える |

まとめた並びの要素の順は、文書の中の出現順（キーの並びの順に深さ優先でたどる）にする。
