## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 待ち時間の上限の値 | `GIT_ARCHIVE_TIMEOUT_SEC` を 20 秒にする | 負荷の高い間（load average 15〜21）に 30 回測った最長 12.3 秒に 50% の余裕を追加して切り上げた |
| 待ち時間の上限の持ち方 | `run_git` に `timeout`（`None` で `GIT_TIMEOUT_SEC`）を追加し、`SnapshotStore.checkout` と `export_paths_at` の `git archive` だけ `GIT_ARCHIVE_TIMEOUT_SEC` を指定する | 他の git の呼び出しは 8 秒のまま |
| 上限を超えたとき | 今と同じく `timed_out=True` の `GitError` を送信し、`{commit}.tmp` を削除する | - |
