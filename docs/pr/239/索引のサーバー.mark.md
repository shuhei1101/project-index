## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 配信元の設定 | ai-monitor の反映作業の実行スクリプトを作業ブランチの worktree で流し、種類の行を追加する | 追加した行の検査・パスは実行スクリプトの値のまま |
| MCP サーバーの定義 | 文書の MCP・管理の MCP ごとに `docs/mcp-server/` へ 1 ファイル作成する。ツールの入出力はインターフェース定義を参照し、設計書に重ねて書かない | 接続先は `plugins/project-index/.mcp.json` の値 |
| instructions・description | MCP サーバーの定義の記載と食い違う文面を設計書に合わせて書き直す | ツールの入出力は変えない |
