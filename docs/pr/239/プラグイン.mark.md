## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| エージェントフロー | スキルごとに `docs/agent-flow/` へ `type: skill` のエージェントフローを 1 ファイル作成する。ID は用語集の ID と重ならないよう `skill-{スキルの名前}` にする | setup・feedback の手順の本体は今のまま `docs/guide/` のページに持ち、エージェントフローはページを取得して進める工程だけを持つ（利用者が読む公開ドキュメントと手順を 1 か所にするため） |
| SKILL.md の引数 | `$ARGUMENTS` を、エージェントフローの `skill.arguments` の名前（setup は `$path`、global-setup は `$clone`）に書き換え、frontmatter に `arguments` を足す | `argument-hint` は今の値のまま |
| SKILL.md の global-setup のつながりの確認 | 「文書の MCP のツールが 6 つ返る」を、エージェントフローのとおり「全て返る」に直す | 文書の MCP のツールは MCP サーバーの定義で 7 つ |
| SKILL.md のその他 | エージェントフローの工程と食い違う文面を、エージェントフローに合わせて書き直す | スキルの名前は変えない |
