# 要件

## 要望

読み取り API の配信元の設定の取得（`GET /sources/{source}/config`）が、配信元の設定の `direct_commit.kinds[]` のうち `body: false` の種類を返却する。

| 要件 | 終了の条件 |
| --- | --- |
| 返却する API | 配信元の設定の取得の応答に、本文の直コミットを断る種類の並びを追加する。値は配信元の設定（`project-index.yaml`）から決定するため、配信元の設定のうち画面が使用するキーを返却するこの API に追加する |
| 値 | `direct_commit.kinds[]` の `{id, body: false}` の要素の `id` を、記載の順に並べる。文書の MCP の `describe` の `metadata_only_kinds` と同じ値になる |
| `direct_commit` が無い・`body: false` が無い配信元 | 空の並びを返却する |
| 端末の設定を重ねた配信元 | 端末の設定の `config` を重ねた後の配信元の設定の値を返却する |
| 既存の項目 | 既存の `nav`・`documents`・`decisions`・`github`・`diff`・`schemas` の値は変えない |

`未確定`: 応答の項目の名前（決める段: インターフェース定義設計）

| 案 | 内容 | メリット | デメリット |
| --- | --- | --- | --- |
| A | `directCommit.metadataOnlyKinds` | 配信元の設定の `direct_commit` の下の値であることが名前から分かる。後で `direct_commit` のほかの値を返却するときに同じオブジェクトへ追加できる | 1 つの値のためにオブジェクトを 1 階層挟む |
| B | 最上位の `metadataOnlyKinds` | 画面のサーバーが 1 階層で参照できる | `direct_commit` の値であることが名前から読み取れない |

推奨: A

既存の応答は `decisions.folders`・`diff.ignore_keys` のように配信元の設定のキーの階層のまま返却しており、それに統一される。
