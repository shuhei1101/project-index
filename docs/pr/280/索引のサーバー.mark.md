## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 応答のモデル | `SourceConfigResponse` に、本文の直コミットを断る種類の並びを持つ項目を追加する | 項目は `directCommit.metadataOnlyKinds` |
| 値の組み立て | `get_source_config` が `SourceConfig.direct_commit.metadata_only_kinds` を写す。`direct_commit` が `None` の配信元は空の並び | 端末の設定の `config` を重ねた後の値。`describe` と違い作業場所と端末の設定の `sources[].direct_commit` で絞らない |
| 既存の項目 | 既存のキーと値は変えない | 破壊的変更なし |
| テスト | `direct_commit.kinds[]` に `{id, body: false}` を持つ配信元と、`direct_commit` を持たない配信元の両方を確認する | 単体と結合 |
