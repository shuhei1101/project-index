## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| フックの出力 | `main` は `hookSpecificOutput` に `hookEventName`・`permissionDecision: "allow"`・`permissionDecisionReason`・`updatedInput` を出す | `permissionDecisionReason` は、文書の MCP の入力に作業場所とセッションを入れた旨の固定の文 |
| 入力が読めないとき | 何も出さず終了コード 0 で戻る振る舞いを変えない | 許可・拒否を判断しない |
| IF-20 | 正常系の期待値を「出力の `permissionDecision` が `allow`」へ、出力の例と `constraints` の「許可の判定」を `allow` を返し設定の deny・ask のルールが効く内容へ直す | インターフェース定義設計の工程 |
| MOD-4 | `main` の処理の手順 2 と `test_main` の期待値を直す | モジュール構成設計の工程 |
| テスト | 単体の `test_main`・結合の `test_normal` の `permissionDecision` の不在の確認を、`allow` であることの確認へ反転する | 読めない入力のテストは変えない |
