# 要件

## 要望

PreToolUse のフックは、書き換えた入力を返すときに `hookSpecificOutput` へ `permissionDecision: allow` と `permissionDecisionReason` を入れて返す。

- フックが当たるのは `hooks.json` の matcher `mcp__plugin_project-index_project-index__.*` の文書の MCP のツールだけで、`allow` を返しても権限の確認を省くのは自分の MCP のツールに限られる
- 設定の deny・ask のルールは、フックの返却によらず評価される
- 入力が読めないときに何も出さず終了コード 0 で戻る振る舞いは変えない
- 単体・結合テストは、出力に `permissionDecision: allow` があることを確かめる
- プロジェクトの PreToolUse のフックは `pre_tool_use.py` の 1 つだけで、同じ型の箇所はほかに無い
