## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 書き出し | `_to_yaml_row` で、`direct_commit.scope` が空でなければ `direct_commit.scope`、`direct_commit.kinds` が空でなければ `direct_commit.kinds` を行に記載する。両方とも既定値なら `direct_commit` を記載しない | 既定値と同じキーを記載しない今の決まりに合わせる |
| 丸ごとの保存の補完 | `_fill_unsent` で、行に `direct_commit` を含めなかったときはファイルの同じ配信元の行の値で埋める。含めたときは `scope`・`kinds` を別々に、送信したかで決める | `scope` の `read`・`write` と同じ決め方 |
| 1 行の変更 | `SourcePatch` に `direct_commit` を加え、`_apply_patch` で送信した `scope`・`kinds` だけを重ねる | 送信しなかったときはファイルの行の値を残す |
| 1 行の追加の同じ内容の判定 | 同じ id の行があるときの内容の比較（`same`）に `direct_commit` も含める | `_to_yaml_row` どうしの比較のため、書き出しを修正すれば含まれる |
| 既存の操作への影響 | `direct_commit` 以外のキーの書き出し・補完・検証・応答は変えない | - |
| 端末の設定のスキーマ | 変えない（`sources[].direct_commit` は既にある） | - |
