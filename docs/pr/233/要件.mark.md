# 要件

## 要望

端末の設定の API の次の操作で、`sources[].direct_commit`（`scope`・`kinds`）を端末の設定のファイルの行へ書き出す。

| 操作 | 書き出す値 |
| --- | --- |
| `POST /settings/sources`（1 行の追加） | 送信した行の `direct_commit`。既定値（`scope` が `[]`・`kinds` が `{}`）のキーは記載しない |
| `PUT /settings/sources`（丸ごとの保存） | 送信した行の `direct_commit`。行に `direct_commit` を含めなかったときは、ファイルの同じ配信元の行の値を残す |
| `PATCH /settings/sources/{id}`（1 行の変更） | 送信した `direct_commit`。送信しなかったときは、ファイルの同じ行の値を残す |

`direct_commit` の `scope`・`kinds` は、`scope` の `read`・`write` と同じく、送信したキーだけを置き換え、送信しなかったキーはファイルの行の値を残す。
書き出した後の再読み込みで、`direct_commit.scope` に該当する作業場所から直コミットを呼べる。
既定値と同じキーを記載しない今の書き出しの決まりと、`direct_commit` 以外のキーの書き出しの結果は変えない。
