# 要件

## 要望

`/project-index:setup` がプロンプトの行の候補の了承を受けて `{clone}/schemas/prompt.schema.yaml` を配信元へコピーするとき、`$ref` 先の `{clone}/schemas/common.schema.yaml` も同じ `schemas/` へコピーし、配信元でプロンプトのスキーマを解決できるようにする。

| 運用 | プロンプトのスキーマ | 共通の型 | `$ref` |
| --- | --- | --- | --- |
| コミットする | `schemas/prompt.schema.yaml` | `schemas/common.schema.yaml` | 書き換えない |
| ローカル運用 | `schemas/prompt.schema.local.yaml` | `schemas/common.schema.local.yaml` | コピーした `prompt.schema.local.yaml` の `common.schema.yaml#/$defs/id` を `common.schema.local.yaml#/$defs/id` に書き換える |

- 共通の型のコピー先に既にファイルがある場合は上書きしない。そのファイルが `$defs.id` を持たない場合は、利用者に示して止まる
- 終了の条件: SC-5 の「正常シナリオ（content/prompts/ を見つける）」で、配信元の `schemas/` にプロンプトのスキーマと共通の型があり、`check_project` が違反を 0 件で返却する
