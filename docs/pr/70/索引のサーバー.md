## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| クラス図の `click` | `href "./MOD-{n}.py.yaml#{見出し}"` を `href "id:MOD-{n}#{項目のパス}"` へ書き換える | `未確定`（[要件](./要件.md) の描画の対応） |
| 文書のスキーマ | `common.schema.yaml` の `$defs` に文書の `tags`・`aliases` を定義し、設計書の種類のスキーマから任意のキーとして参照する | 既存の文書を壊さない |
| 用語集 | `alias_type: term` の種類を新設し、`docs/guide/用語集.md` の用語を移す | `未確定`（[要件](./要件.md) の配置先と形式） |
| タグ・エイリアス | 設計書と公開ドキュメントへ `action:`・`topic:`・`tool:` のタグ（`main` を 1 つ）を付け、判定フローチャートで判定したエイリアスを登録する | 付ける前に `group_by: tags` で使用中のタグを確認する |
| 文言 | [要件](./要件.md) の置き換え先で置き換える | 見出しを変えた箇所はリンクのアンカーと本文の呼び名を揃える。識別子とコードは変えない |
| 検査 | 書き換えた後、管理の MCP の `check_project` で配信元の設定と文書の検査が通ることを確かめる | - |
