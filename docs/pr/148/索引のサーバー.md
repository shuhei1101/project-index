## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 使用できる項目 | `nav` の検査用に、`known_fields` の結果へ有効な行の `metadata` のキーを、対応付けた列の型（その行のスキーマだけで作った使える項目の列名の型。無ければ `string`。dev-docs の画面と同じ決め方）で加える関数を `search/fields.py` に配置し、`nav_warnings` と `_nav_documents` から呼ぶ | 既に使用できる項目のキー（共通のキー・スキーマの項目）は上書きしない。`known_fields` 自体は変えない |
| 項目の値 | `field_values` と `match_filter` に、文書の行の `metadata`（行の ID → 共通のキー → 列名）を任意の引数で指定できるようにし、`METADATA_KEYS` に無いキーは対応付けた列から取得する | 引数を指定しない `search_docs`・`list_changes` の照合は変わらない |
| 数え上げ | `nav_auto_counts` と `_select` が、行の `metadata` を照合に指定する | `nav_warnings`・`write_nav` の両方の数え上げで有効にする |
| 既存機能への影響 | `search_docs`・`list_changes` の受け付ける項目は変えない | スコープ外の行を参照 |
