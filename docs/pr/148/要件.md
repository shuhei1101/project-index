# 要件

## 要望

`nav` の `auto.filter` の検査と数え上げで、有効な文書の行の `metadata` で対応付けたキーを使用できる項目として扱い、dev-docs の画面（[shuhei1101/dev-docs#262](https://github.com/shuhei1101/dev-docs/pull/262)）と同じ条件を受け付ける。

| 対象 | 終了の条件 |
| --- | --- |
| 使用できる項目 | 起動時と `describe` の警告（`nav_warnings`）・`check_project`・`write_nav` の検査が、行の `metadata` のキーを、対応付けた列の行のスキーマの型（列がスキーマに無ければ `string`）で使用できる項目に加える。shuhei1101/observability の `files_guide` の行（`metadata: {category: category}`）に `auto.filter: {field: category, op: eq, values: [...]}` を適用して「知らない項目」の違反が 0 件 |
| 該当する文書の数 | `nav_auto_counts` の照合が、`METADATA_KEYS` に無い `metadata` のキーの値を対応付けた列（`metadata[キー]`）から取得する。`metadata: {category: section}` の行で `field: category` の条件が `section` の値で文書に該当し、「該当する文書がありません」の警告を出さない |
| 変えない範囲 | `search_docs`・`list_changes` の `filter` が受け付ける項目と照合は変えない |

## 変更箇所の由来

| 対象箇所 | commit | 目的 | 変更回数 | 影響 |
| --- | --- | --- | --- | --- |
| `read/nav.py` の `nav_warnings`・`admin/service.py` の `_nav_documents` | [c19c617](https://github.com/shuhei1101/project-index/commit/c19c617d9b61cf5fbfd3c6e386e468e690e6f4ba)（`dev-docs の文書の MCP・管理の MCP・配信元の読み込みとプラグインを移し、… (#15)`） | dev-docs から検査を移したときに、`search_docs` と同じ `known_fields`（行のスキーマと共通のキー）で使用できる項目を作った。行の `metadata` のキーを除く目的は読み取れない | 2 回（[81f0e70](https://github.com/shuhei1101/project-index/commit/81f0e70ecda123ed3ed882b54e33fbbe4ad29d68) は lint の修正だけ） | `nav` の検査に限って項目を加える修正は、`search_docs` と同じ条件の書式で検査する目的を壊さない |
