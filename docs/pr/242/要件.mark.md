# 要件

## 要望

- `.` を含むマップのキーを項目のパスで指せるようにする
  - 既存の `#` で始まる参照の型の項目のパスの `[{キー}]`（`.` や空白を含んでも 1 階層）で指せる。`unset: ["#notes[mcp/server.py の補足]"]` で削除し、`set: {"#notes[{新しいキー}]": ...}` で追加できる（develop の `fields.py` の `delete_field` に MOD-3038-6 の `notes` を当てて、キーが消えることを確かめた）
  - 新しい書き方は足さず、制約「unset の項目のパス」とガイド『文書のMCP』の `unset` の説明から、`.` を含むキーをこの書き方で指すことを案内する
- `#` で始まらない `unset` の要素の項目が無いときは、今までどおり何もせず、その要素を `results[].skipped_unset` に返却する
  - 違反にはしない。IF-6 は「項目が無ければ何もしない」を今の仕様として定めており、違反にすると今通る呼び出し（無い項目を念のため消す `unset`）を断る破壊的変更になるため
