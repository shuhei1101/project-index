## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 項目のパスの解釈 | `.` で単純に分けず、区切りの中の `["..."]` を 1 つのキーとして読む字句解析にする。`[` の直後が `"` なら引用符で囲んだキー、それ以外は今までどおり順番か配列の要素の選び方 | 引用符が閉じない・`]` が続かないパスは今の「記載方法が誤っています」の違反にする |
| 項目のパスの例の文 | `PATH_EXAMPLE` と違反の文に引用符で囲んだキーの例を加える | - |
| 解決できない unset | `#` で始まらない要素が項目へ解決できないときの返し方を変える | `未確定`（決める段: インターフェース定義設計。案は [要件](./要件.mark.md)） |
| 共通のキーの列名への読み替え | 先頭のキーが引用符で囲んだキーでも、共通のキーと一致すれば今までどおり読み替える | - |
| 既存の呼び出し | 引用符を含まないパスの読み方は変えない | - |
