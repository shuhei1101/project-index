## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 何もしなかった操作 | `unset`・`remove_from` の 4 つの経路（[要件](./要件.mark.md)）で何もしなかったときは、今までどおり何もせず、項目のパス（`unset.{要素}`・`remove_from.{キー}`）と理由を `results[].skipped` に返却する | 該当するものが無ければキーを出さない。`failed` では返却しない |
| `.` を含むキー | 新しい書き方は足さず、既存の `#` で始まる参照の型の項目のパスの `[{キー}]` で指すことを、IF-6 の制約「unset の項目のパス」とガイドで案内する | - |
| 既存の呼び出し | 違反にしない。`status`・`version`・書き込みの扱いは変えない | - |
