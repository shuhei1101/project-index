## 要望

設計書・ガイド・スキーマの例・コードのコメントと docstring・テストの docstring に残る「控え」（控える・控えた・控えの場所 など）を、AI slop の単語の対応表（shuhei1101/knowledge の `docs/word-list/word-list-ai-slop.yaml`、develop。`控える` → `記録`）の置き換え先に修正する。
置き換え先は [PR #56](https://github.com/shuhei1101/project-index/pull/56)・[PR #63](https://github.com/shuhei1101/project-index/pull/63) の置き換え（変換の結果の控え → 変換の結果のキャッシュ）と統一し、意味ごとに次のとおり選ぶ。

| 意味 | 今の文言の例 | 置き換え先 |
| --- | --- | --- |
| 結果を次の呼び出しで使い回すために持つもの | 変換の結果の控え・検査の控え・配信元の検査の控え・行の控え・控えの場所・控えを捨てる・配信元の控えの破棄・配信元の一覧の今の控え | キャッシュ（変換の結果のキャッシュ・検査のキャッシュ・配信元の検査のキャッシュ・行のキャッシュ・キャッシュのフォルダ・キャッシュを捨てる・配信元のキャッシュの破棄・配信元の一覧の今のキャッシュ） |
| 結果を使い回すために持つ動作 | 結果を控える・控えない・控えがあればそれを使う | キャッシュする・キャッシュしない・キャッシュがあればそれを使う |
| 後の手順で使う値を変数・属性に持つ動作 | 番号を控える・前の HEAD を控え・控えたメソッド・受けた値を控える偽物・新しい内容を控え | 記録する・記録したメソッド・受けた値を記録する偽物 |
| 利用者がキーを手元に持つ動作 | 作ったキーを控える | 作ったキーを記録する |
