# 変換の結果のキャッシュのキーに変換のスクリプトの状態を含め、スクリプトを書き換えた後に前の結果を返却しないようにする

## 概要

利用者かエージェントが変換のスクリプトのファイルを書き換えたとき、次の変換から、書き換えた後のスクリプトで変換した結果を返却するようにする。

## 背景

[Issue #182](https://github.com/shuhei1101/project-index/issues/182) の不具合。
変換の結果のキャッシュ（`ConvertService._cache_path`）のキーは (配信元の ID, 種類, 変換の ID, 文書のバージョン, `run` のハッシュ, `RUNNING_VERSION`) で、変換のスクリプトのファイルの状態を含まない。
そのため、文書のバージョンが変わらない限り、スクリプトを書き換えても変わる前の変換の結果を返却する。

作業 PR [#181](https://github.com/shuhei1101/project-index/pull/181)（起点 Issue [#178](https://github.com/shuhei1101/project-index/issues/178)）で、検査の読み取りの結果のキャッシュのキーにスクリプトの状態を加えた。
その調査で同じ型の欠けが変換の結果のキャッシュにもあると分かり、#181 のスコープ外として切り出した。
