## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 変換の結果のキャッシュのキー | 今のキーに、変換のスクリプトの状態を加える | 置き場所と関数の分け方はモジュール構成設計で決める |
| スクリプトの状態 | クローン本体で `config_commit` があればスクリプトを取り出す commit、それ以外（worktree・`config_commit` の無い配信元）は `run` が指すファイルのフォルダの配下の `stat` で表す | #181 の `DocumentChecker._read_key`・`_script_stamp` と同じ作り方。モジュール構成設計の結果: `_script_stamp` と配下の関数を検査の service.py からスクリプトの実行の scripts.py（MOD-88）へ移して公開の `script_stamp` にし、検査（`_cached_stamp`）と変換（`ConvertService._cache_path`）の両方から使用する |
| `cache: false` の行 | 今までどおりキャッシュを参照も保存もしない | スクリプトの状態を作らない |
| 既存機能への影響 | 入出力の構造は変えない。`reload` で全てのキャッシュを削除する振る舞い（`clear`）と、`try_convert` がキャッシュに保存しない振る舞いは保つ | - |
