# 要件

## 要望

`converters[]` の行の `cache` が `true` の変換が、変換する場所のスクリプトで変換した結果を返却し、スクリプトを書き換える前の結果を返却しない。

| 変換する場所 | 終わりの条件 |
| --- | --- |
| worktree・Git の管理外の配信元 | 行が指す変換のスクリプトのファイル（同じフォルダの配下の import 先を含む）を書き換えた後、次の変換から、書き換えた後のスクリプトで変換した結果を返却する |
| クローン本体（`default_ref`） | スクリプトを取り出す commit（`config_commit`）が進んで変換のスクリプトが変わった後、その commit のスクリプトで変換した結果を返却する |

- スクリプトの書き換えは、commit していない状態・commit して push した状態のどちらでも、次の変換から書き換えた後で変換する。`reload`・再起動を要さない
- 同じ文書を、同じ行・同じスクリプトで変換するときは、2 回目からキャッシュを使い回し、スクリプトを動かし直さない
- スクリプトの状態の作り方は、#181 で検査の読み取りの結果のキャッシュに入れた作り方（MOD-75 の `_script_stamp`）に合わせる
- `cache: false` の行の変換は今までどおりキャッシュを参照も保存もしない
