# 要件

## 要望

- `write_docs`（`op`: `update`）の `unset` の項目のパスが `#` で始まるとき、`text_edits`・`add_to`・`remove_from` と同じ解釈（種類のスキーマの `x-key` の値で配列の要素、`[{キー}]` で辞書のキーを指す）で文書の中の 1 つの項目へ解決し、その項目を削除する
- `#` で始まるパスが解決できない（無い要素・`x-key` の無い配列・無い順番・無いキー）とき、`unset.{パス}` の違反を返却して書き込まない
- `#` で始まらないパスに要素の選び方（`[...]`・`**.`）を含めたとき、`InvalidArgumentError` をそのまま送信せず、`unset.{パス}` の違反を返却して書き込まない
- `#` で始まらず要素の選び方を含まないパスは今までどおりで、項目が無ければ何もしない
