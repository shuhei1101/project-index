## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| `unset` の `#` で始まるパス | `resolve_ref_path` で種類のスキーマの `x-key` の値から文書の中の 1 つの項目の位置へ解決し、その位置の項目を削除する | 共通のキーの列名への読み替えはしない（`add_to`・`remove_from` と同じ） |
| 解決できないパスの違反 | `#` で始まるパスを解決できないとき、`#` で始まらないパスに要素の選び方（`[...]`・`**.`）を含めたときは、`unset.{パス}` の違反にして書き込まない | 違反の文言は `add_to`・`remove_from` の違反にそろえる |
| `#` で始まらず要素の選び方を含まないパス | 今までどおり、無い項目は飛ばす | - |
