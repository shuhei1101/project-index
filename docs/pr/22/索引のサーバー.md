## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 保存（編集機能） | `save_sources` は、送信された行ごとに、ファイルの同じ配信元の行（`id`、無ければ配信元の設定の `name`）を探し、送信された行に無いキー（`SourceEntry` の `model_fields_set` に無いキー）をファイルの行の今の値で埋めてから記載する | 同じ配信元の行が無い行は既定値のまま |
| 保存の書き方 | 埋めた後の行を今の `_to_yaml_row` で記載する（既定値と同じキーは記載しない） | - |
| 取得（閲覧機能） | `SettingsSourceRow` に `outside_read` を加え、`GET /settings/sources` の行に `outsideRead` を返却する | 記載していない行は `true` |
| 既存機能への影響 | 送信するキーを変えない今の画面のまま、`outside_read: false` が残る。`outside_read` を送信する呼び出し側は今と同じく送信した値で記載する | 破壊的変更なし |
