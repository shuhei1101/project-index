# 要件

## 要望

- `PUT /settings/sources` で保存したとき、送信された行に無いキーは、ファイルの同じ配信元の行（`id`、無ければ配信元の設定の `name` で照合する）の今の値で残す
  - 例: ファイルに `outside_read: false` を記載した行を、`outside_read` を含めずに送信して保存しても、ファイルの行に `outside_read: false` が残る
  - 送信された行に含めたキーは、送信した値で記載する（`outside_read: true` を送信すれば `outside_read` をファイルから削除する）
  - ファイルに同じ配信元の行が無い（新しく追加した）行は、今と同じく既定値で記載する
- `GET /settings/sources` の行に `outsideRead` を含める（インターフェース定義の IF-30 には既にあるが、実装の `SettingsSourceRow` に無い）
