## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 索引の同期 | 管理用の YAML のフォルダの配下でも、ほかの `documents` の行の `paths` に当たり、その行の `exclude` に当たらないファイルを「管理用の YAML に無いファイル」に数えない | IF-12 の `正常系（ほかの行の文書になるファイルを数えない）`。起動時の警告・`status` も同じ判定 |
| `project-index files` | `--exclude-path`（`documents[].paths` と同じ書き方の glob）に当たるファイルを結果から外す | IF-17 の `正常系（除外するパスを渡す）` |
