## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 管理用の YAML の追加の候補 | プロンプトの行（`{config}` に既にある行と、候補として加える行）の `paths` に当たるファイルを、`project-index files` の結果から外す | プロンプトの行の `paths` を `project-index files` の `--exclude-path` に渡す（IF-17） |
| 管理用の YAML の既存の行 | プロンプトの行の `paths` に当たるファイルの行を、削除の候補にする | 2 回目以降で、前の setup が記載した行を消す |
| 確認の表 | 外したファイルと削除の候補を、プロンプトの行の候補と同じ表で示す | 断られたら何も書き換えない（今の手順のまま） |
| シナリオ | SC-5 の「content/prompts/ を見つける」に、範囲が配信元の直下の `**/*` で管理用の YAML がプロンプトの YAML の行を持つ前提と、記載した後に `search_docs` がプロンプト 1 つにつき 1 件だけ返す期待値を加える。初回で範囲を既定の `**/*` にしてプロンプトの YAML が管理用の YAML の候補に出ないシナリオを加える | - |
