## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 扱うか | 扱う（確認ログのとおり） | - |
| 配信元の設定を指す方法 | 書き込みの API に配信元の設定の項目を追加し、文書とは別に許可する。キーの名前はインターフェース定義設計で決める | - |
| 検査 | 書き換えた後の配信元の設定を、スキーマと起動・`reload` と同じ検証にかけ、違反は 422 の `errors[]` で返す | - |
| 書き換えられないキー | `validators`・`converters`・`generators`・`direct_commit`・`worktrees` が書き換える前と違う要求は断る | - |
| 原本の取得 | 端末の設定を重ねる前の `project-index.yaml` の内容とバージョンを返す読み取り API を用意する。`config` が配信元のフォルダの `project-index.yaml` 1 つでない配信元は書き込みで断る | - |
| 許可 | 端末の設定と配信元の設定の両方で許可した配信元だけを書き込める。許可していなければ 403 | - |
| 反映 | コミットしてプッシュした後に、その配信元を再読み込みする | - |
| 既存機能への影響 | 配信元の文書の書き込みと、許可していない配信元の振る舞いは変えない | - |
