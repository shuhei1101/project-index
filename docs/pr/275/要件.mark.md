# 要件

## 要望

- dev-docs の画面のサーバーが、書き込みの API（`POST /sources/{source}/commits`）で配信元の設定 `project-index.yaml` を直コミットで書き換えられるようにする
- 書き込みの API に配信元の設定の項目を追加し、端末の設定と配信元の設定に、文書の種類とは別の配信元の設定の直コミットの許可のキーを追加する。両方で許可した配信元だけを書き換えられる
- 書き込む前に配信元の設定のスキーマ（`src/project_index/schemas/project-index.schema.yaml`）と配信元の設定の検証（起動・`reload` と同じ判定）に合格しない変更を断る
- コマンドを持つキー（`validators`・`converters`・`generators`）を書き換える要求は断る（スクリプトの変更は PR を経る）
- 画面は配信元の設定の原本（端末の設定を重ねる前の `project-index.yaml` の内容）とバージョンを読み取り API で取得し、書き換えた内容とそのバージョンを送信する。端末の設定の `config` が配信元のフォルダの `project-index.yaml` 1 つでない配信元は断る
- 書き込みの API が書き換えた配信元の設定を、再起動せずに配信へ反映する
