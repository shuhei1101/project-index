## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| `src/files.yaml` | `src/` からの相対パスで `project_index/` 配下の `.py` を 1 ファイル 1 行で並べ、`name`・`description`・`tags`・`related` を記載する | `related` は `container` がそのファイルを指すモジュール構成の設計書への `implements`。`tests` の `related.to` は配信元の直下からのパス（`src/project_index/...`・`plugins/project-index/hooks/...`） |
| `tests/files.yaml` | `tests/` からの相対パスで `.py` を 1 ファイル 1 行で並べる | 単体テストはモジュール構成の `test_files` から、テストするコードの行への `tests`。結合テストは `test_file` から、インターフェース定義への `tests` |
| `project-index.yaml` | `documents[]` に `src`・`tests` の行を加える | `schema: schemas/files.schema.yaml`・`records: files`・`body_file: path`。`exclude` は `src` が `["*.schema.yaml", "aliases.source.yaml", "steps.yaml"]`（管理用の YAML `files.yaml` 自身に該当するパターンは入れない）で、`tests` は持たない。空か再エクスポートだけの `__init__.py` は「載せるファイルの判定」で除かれ、定数を持つ `project_index/__init__.py` は MOD-6 への `implements` を持つ行として載せる。`metadata.id` は置かず、文書の ID は配信元の直下からのパス（`src/project_index/main.py`）にする |
| `MOD-1` の `directory` | `src/files.yaml`・`tests/files.yaml` を加える | モジュール構成設計の工程 |
| 対応の作り方 | モジュール構成の `container`・`test_files` とインターフェース定義の `test_file` から `related` を組み、手で記載する `name`・`description` と合わせる | 対応表に無いファイルは `related` を持たない |
