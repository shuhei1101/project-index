# write_docs の create で、既にある本文のファイルを指す記録を作成できるようにする

## 概要

エージェントが、先に作成した本文のファイルを指す記録を、`write_docs` で作成できるようにする。

## 背景

[Issue #218](https://github.com/shuhei1101/project-index/issues/218) の要望。MindStella のワークスペースの配信元（`records: items`・`body_file: body`）で、本文のファイルを先に Write で作成した後、そのファイルを指す記録を `write_docs` の `create` で作成できず、YAML へ直接追加した。

- `data.body` だけを指定すると、`@body` が無いため「本文のファイルの作成には本文（@body）が要ります」で断られる
- `data.body` を除くと、スキーマの必須（`body`）で断られる
- `@body` を加えても、既にあるファイルを指す `create` は「本文のファイル {パス} は既にあります」で断られる
