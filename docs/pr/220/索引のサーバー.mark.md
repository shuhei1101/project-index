## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 既にあるファイルを指す作成 | `create` の `data` の `body_file` の列が配信元の中の既にあるファイルを指し、`@body` が無く、配信元のどの文書のファイル（ほかの行の文書・管理用の YAML・要素の本文のファイル）でもなければ、要素だけを書き込み、そのファイルを本文のファイルとする | 本文のファイルは書かない |
| 本文のファイルを持たない要素へ付ける | `update`・`replace` で `body_file` の列だけを指定したときも、作成と同じ条件で既にあるファイルを本文のファイルとして付ける | - |
| 断る条件 | 指すファイルが無く `@body` も無い・`@body` があり指すファイルが既にある・指すファイルが配信元のいずれかの文書のファイル・配信元の外を指す、は今どおり `body_file` の列か `@body` の違反で断る | - |
| エラーの直し方 | 違反の `fix` に、取れる方法（`@body` を加える・先に本文のファイルを作成する・`@body` を除いて既にあるファイルを使う・新しいファイルのパスにする）を条件ごとに示す | - |
| 既存の操作への影響 | `@body` を指定した作成・更新、本文のファイルを持つ要素の操作の結果は変えない | - |
