## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 参照の型の項目のパスの書き方 | `[...]` の中の値に `[` `]` を含む要素・キーを指す書き方を IF-6 の制約「参照の型の項目のパス」に追加する | 対応の取れた `[` `]` は値の一部として読み、対応の取れない `[` `]` は記載方法の誤り |
| `resolve_ref_path` の解釈 | 決めた書き方で `[...]` の値を切り出し、既存の `x-key` の値・`#{順番}`・辞書のキーの解決へ渡す | `text_edits`・`add_to`・`remove_from`・`unset` は `resolve_ref_path` を共有するため、解釈の修正 1 か所で全てに効く |
| 既存の書き方 | `[` `]` を含まない値の書き方と解決結果を変えない | - |
