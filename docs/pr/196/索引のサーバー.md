## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 日時を付けない指定 | `documents[].write_dates`（真偽、省くと `true`）を追加する。`write_docs` は Git 管理外の配信元でも、書き換える文書の種類のこのキーが偽なら `_stamp` を呼ばない（改名の参照元・`replace_text` を含む） | - |
| 本文のファイルを持たない要素の読み込み | `body_file` の列が無い・値が空の要素は、`body_file` を持たない `records` の行と同じ本文・ID・名前で文書にする。列の値があってファイルが無い・配信元の外を指す要素だけ `missing_body_file` にする | 索引の同期の `missing_body_files` も同じ条件になる |
| 本文のファイルを持たない要素の書き込み | `create`・`update` の `@body` と `body_file` の列の扱いを、[要件](./要件.md) の決定に合わせる。`rename` の `new_path`・`delete_docs` の本文のファイルの削除は、本文のファイルを持たない要素では `body_file` を持たない `records` の行と同じに扱う | - |
| 警告の行 | `search_docs` の読み込めないファイルの警告を、ファイルと理由ごとに 1 行にまとめ、件数と先頭の要素の詳細を添える | - |
| 既存の配信元への影響 | 指定を省いた配信元の書き込みと、本文のファイルを持つ要素の読み込みは変えない | - |
