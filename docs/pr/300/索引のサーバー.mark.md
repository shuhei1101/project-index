## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 検索機能 | `search_words` が返却する文書ごとに、本文と語を `body` の `contains` の条件（`snippet_lines` と同じ条件）にして `count_matches` で数え、`SearchItem.match_count` に入れる | 応答のキーは camelCase の `matchCount` |
| 既存機能への影響 | 既存のキー・`items` の並び順・`totalCount`・`excludedCount` は変えない | 既存の単体・結合テストで回帰を確認する |
| SC-11・IF-28・MOD-78・MOD-79 | 単語での検索の期待値・応答の項目・関数の処理と単体テスト・型の項目に一致した行の数を追加する | - |
| ガイド | HTTP の API のガイドの語での検索の行の返すものに、文書ごとの一致した行の数を追加する | - |
| 性能 | 一致した行の数は返却する `limit` 件の文書だけで数える | 本文の行の照合を 1 回増やすだけ |
