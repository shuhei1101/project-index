# 要件

## 要望

語での検索（`GET /sources/{source}/search`、IF-28）の応答の `items[]` に、その文書の本文で一致した行の数 `matchCount`（int）を加える。

| 項目 | 振る舞い |
| --- | --- |
| `items[].matchCount` | 文書の本文のうち、`snippets` と同じ判定（空白で区切った語のどれかを、NFKC と casefold をして含む行）に当たった行の数。`snippets` の 3 件の上限に関わらず、本文の全ての行を数える |
| 付ける文書 | `include_excluded` の値に関わらず、返却する全ての `items` に付ける |
| 本文に一致した行が無い文書 | 語の照合が本文以外の項目（名前・ID 等）で当たった文書は `0` |
| SQLite の表の行の文書 | `columns[]` の列の値を本文として数える（`snippets` と同じ本文） |

- 既存のキー（`totalCount`・`items[].path`・`id`・`filePath`・`name`・`snippets`・`excluded`・`excludedCount`）と、`items` の並び順（文書のページのパスの昇順）は変えない
- 同じ行が複数の語を含んでも 1 行と数える
