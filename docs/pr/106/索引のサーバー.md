## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| アウトラインの取り出し | 範囲のファイルごとに、既に持つ説明・見出し・サイズ・コードブロックの割合と言語・リンクの数・関数名・クラス名・import と、次の段階へ進むかの判定と理由を JSON Lines で出す `project-index outline` を追加する | [IF-106-1](../../interface/IF-106-1.yaml) |
| 変わったファイルの一覧 | 確認の時点（無ければ管理用の YAML の最終変更）から中身が変わった行のファイルを、未 commit の変更を含めて出す `project-index changed` を追加する | [IF-106-2](../../interface/IF-106-2.yaml) |
| 確認の時点の記録 | 管理用の YAML の直下の `checkpoint` に、Git の配信元は HEAD の commit と見直した未 commit のファイルの SHA-256、Git 管理外は日時を書く `project-index checkpoint` を追加する | [IF-106-3](../../interface/IF-106-3.yaml)。`templates/files.schema.yaml` に任意のキー `checkpoint` を追加する |
| 置き場所 | MCP のツールにせず、setup が既に呼ぶ `project-index` の CLI のサブコマンドにする | 管理用の YAML に記載するファイルの判定を `files` と同じ実装で持てる |
