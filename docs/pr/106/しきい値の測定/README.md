## 判定と、見出しと冒頭で決められなかったファイルとの一致

project-index で `true` になった 6 件を開いて確かめた。

| ファイル | 理由 | 見出しと冒頭で決められるか |
| --- | --- | --- |
| `README.md` | 見出し 1 | 決められる（見出しの直下の 1 段落に受け持ちがある） |
| `docs/guide/documentsの行の判定.md` | コードブロック 0.59 | 決められる（見出しの直下の 1 段落） |
| `docs/guide/新しく作るか修正するかの判定.md` | コードブロック 0.56 | 決められる（見出しの直下の 1 段落） |
| `docs/guide/変更履歴.md` | 見出し 1 | 決められる（見出しの直下の 1 段落） |
| `docs/guide/用語集.md` | 見出し 1 | 決められる（見出しの直下の 1 段落） |
| `docs/pr/5/README.md` | 見出し 1・日本語 0 | 決められない（見出しだけで本文が無い） |

`true` の 6 件のうち 5 件は、段階 3（見出しの直下の最初の段落）で決まる。
判定を誤って `true` にしたときに増えるのは段階 3 の 1 段落の参照だけで、見出しと冒頭を全て読む今の手順より参照は増えない。
knowledge の 26 件は、見出しが 1 つの `確認ログ.md`（表だけ）と本文の無い PR の README が大半で、表の中身を読まないと `description` を決められない。

`false` のファイルで見出しと冒頭で決められないものは、この測定では探していない。
