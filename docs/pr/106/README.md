# setup で仮のメタデータを段階的に読んで付け、2 回目以降は変わったファイルだけを見直す

## 概要

setup の利用者が、ファイルの中身に合った仮のメタデータを受け取れ、2 回目以降の setup で中身が変わったファイルのメタデータを見直せるようになる。

## 背景

[Issue #101](https://github.com/shuhei1101/project-index/issues/101) の要望。
setup スキルの手順 4 は「仮のメタデータは、見出しと冒頭から付ける」の 1 行だけで、どこまで参照するか・分からないときにどう進むかが決まっていない。
見出しが少ないファイル・コードやログが大半のファイル・日本語以外のファイルは、見出しと冒頭では中身が分からない。
2 回目以降の setup は管理用の YAML に無いファイルにしか仮のメタデータを付けず、前回の後に中身が変わったファイルのメタデータは古いまま残る。
