# 要件

## 要望

- 配信元の設定の `documents[].search_exclude` に該当する文書を、次の 3 つのエンドポイントでどう扱うかを決め、決めた扱いで実装する
  - 読み取り API の文書の一覧（`GET /sources/{source}/docs`。dev-docs の画面のサーバーが文書の値・共通のキーとあわせて取得する）
  - 読み取り API の語での検索（`GET /sources/{source}/search`。dev-docs の画面の検索が呼ぶ）
  - 文書の MCP の `list_match_words`
- 既定の結果から除くエンドポイントには、除いた文書も返却する明示の指定を持たせ、指定した結果では除く条件に該当する文書をそれと分かるように返却する（`search_docs` の `include_excluded` と同じ扱い）
- `search_exclude` を記載しない配信元・行の結果は今と変わらない
- 読み取り API の文書の一覧は、`search_exclude` に該当する文書を除かず、各文書に除く条件に該当するかの値を追加して返却する
- 読み取り API の語での検索と `list_match_words` は、`search_exclude` に該当する文書を既定の結果から除き、`include_excluded` を付けたときだけ返却する
