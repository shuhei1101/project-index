## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 重なりの検出 | `check_sync` が有効な行ごとに文書にするファイルを集め、2 つ以上の行に該当するファイルを `{ファイル}: {行の ID}・{行の ID}` の書式で 1 件ずつ返却する | `records` を持たない行はヒットしたファイル、`records`・`body_file` の行は要素の `body_file`。管理用の YAML 自体は数えない |
| `check_project` | 索引の同期の件数・内訳の種類に重なり（`sync.duplicate_files`）を追加する | 重なりの無い配信元は件数 0 |
| 起動時の警告 | `log_source_check` が重なりを 1 行の警告に記載する | 既存の 4 種類と同じ書式 |
| `status`・`describe` の警告 | `status` の同期の件数と引数なしの `describe` の警告に重なりを追加する | 既存の 4 種類と同じく `SyncReport` から作る |
| 参照の型の項目のパス | `text_edits[].field` が `#` で始まるとき、種類のスキーマの `x-key` と文書で位置の項目のパスに解決してから、既存の取得・書き込みで置き換える | `[{値}]`・`[{値}#{順番}]`・辞書の `[{キー}]` は設計書の参照の型と同じ読み方 |
| 既存機能への影響 | `#` で始まらない項目のパスと、`set`・`unset`・`add_to`・`remove_from`・`metadata` の列名・`search_docs`・`list_changes` の項目のパスの読み方は変えない | - |
