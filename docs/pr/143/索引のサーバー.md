## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 重なりの検出 | `check_sync` が有効な行ごとに文書にするファイルを集め、2 つ以上の行に該当するファイルを `{ファイル}: {行の ID}・{行の ID}` の書式で 1 件ずつ返却する | `未確定`: 行が文書にするファイルの範囲（[要件](./要件.md) の案 A / B） |
| `check_project` | 索引の同期の件数・内訳の種類に重なりを追加する | 重なりの無い配信元は件数 0 |
| 起動時の警告 | `log_source_check` が重なりを 1 行の警告に記載する | 既存の 4 種類と同じ書式 |
| `x-key` の値の指定 | 項目のパスの解釈に、`x-key` の値で要素を 1 つ指す書き方を追加する。`[n]`・`[]`・`[{キー}]` の意味は変えない | `未確定`: 書き方（[要件](./要件.md) の案 A / B） |
| `text_edits` | `field` の `x-key` の値の指定を、種類のスキーマの配列の要素の `x-key` で位置に解決してから、既存の取得・書き込みで置き換える | `x-key` を持たない配列・該当する要素が無い・2 つ以上に該当する場合は `text_edits[{n}].field` の違反 |
| 既存機能への影響 | `metadata` の列名・`search_docs` の項目・`list_changes` は新設する書き方を受け付けるかを、インターフェース定義設計で決める | 受け付けない場合は既存の誤りの違反のまま |
