# 要件

## 要望

`documents[].metadata` の `**.` で始まる列（集める対応）は、集めた結果が空の文書でも `metadata` の列の欠けに数えない。
列の欠けは、`**.` で始まらない列（1 つの列を指す対応）で、その列の値が無い文書だけにする。

終了の条件:

- `related: "**.refs[]"` の行で、どの深さにも `refs` を持たない文書が `check_project` の `sync.missing_refs`・`describe` の警告・起動時の警告のログに数えられない
- `**.` で始まらない列の値が無い文書は、今までどおり列の欠けに数えられる
- 入出力の構造（`missing_refs` の件数と並びの書式）は変えない
