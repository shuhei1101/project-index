## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| metadataの列の欠け | `table.metadata` の列名が `**.` で始まる対応は、項目の取得の結果によらず欠けに加えない | `**.` の判定は列名の先頭の文字列で行い、項目のパスの解釈（`parse_field_path` の `AnyDepth`）と同じ規則にする |
| 既存機能への影響 | `**.` で始まらない列は今までどおり `None` を欠けにする。`check_project`・`status`・`describe` の警告・起動の警告のログは件数を引き継ぐだけで変えない | - |
| 設計書 | MOD-25 の `missing_ref_fields` の処理と単体テスト、IF-12・IF-8 の `missing_refs` の説明に、`**.` で始まる列は数えないことを追加する | - |
