# 要件

## 要望

| 要望 | 終了の条件 |
| --- | --- |
| 配信元ごとに読み書きの方法を指定する | 端末の設定の配信元の行に `storage.type`（`git`・`disk`）を指定できる。省略すると、配信元のフォルダが Git の作業ツリーの中なら `git`、外なら `disk` になり、今の動きと変わらない。Git の作業ツリーの外部のフォルダに `git` を指定した行は端末の設定の違反になる |
| `disk` の配信元を Git を参照せずに配信する | Git のリポジトリの中のフォルダでも、`disk` の配信元は設定・スキーマ・`validators`・`converters` のスクリプト・文書・管理用の YAML を、登録したフォルダのファイルから参照し、`default_ref`・リポジトリの直下・メインのリポジトリを求めずに検証・配信する |
| `disk` の配信元をどの作業場所からも同じ内容で参照する | ワークツリー・クローン本体・リポジトリの外部の作業場所・読み取り API のどこから参照しても、登録したフォルダの文書を返却する。`worktrees[]` に該当する作業場所でも、参照の先をワークツリーに読み替えない |
| `disk` の配信元をクローン本体へ書き込む | `write_docs`・`delete_docs` は、作業場所が `scope.write` に該当すれば登録したフォルダへ書き込む（クローン本体でも断らない）。書き込んだ文書に `created`・`updated` を追加する。`writable: false` の種類の文書は削除できない |
| `disk` の配信元で Git に依る機能を受け付けない | 文書の MCP の `ref` の引数と `list_changes` の区間を指定すると誤りを返却する（`list_changes` は前回参照した時点からの変更だけ）。読み取り API の `ref` のクエリは無視し、応答の `ref` は空にする。`GET /refs` は Git 管理外の配信元と同じく `git: false` を返却する。`describe(source)` はブランチ・タグ・ワークツリーを、`trace_related` は一緒に変わったファイルを返却しない。ファイルの日時は文書の `created`・`updated` の値（無ければ空）にする |
| `disk` の配信元の設定の変更を `reload` で反映する | 設定・スキーマ・スクリプトの変更は commit を待たず、`reload` を呼んだ後の要求から使用する |
| 端末の設定の API で `storage` を読み書きする | `GET /settings/sources` が行の `storage` を返却し、`PUT /settings/sources`・`POST /settings/sources`・`PATCH /settings/sources/{id}` が行の `storage` を受け付けて保存する |
| 管理の MCP の `check_project` で `disk` の配信元を検査する | `check_project` に `storage.type` を指定する引数を追加し、`disk` を指定すると Git を参照せずに検査する。フォルダではなく設定のファイルの絶対パス（`project-index.local.yaml` など）を指定できる |
| ローカル運用のファイルを管理用の YAML の対象から除く | `*.local.*` の名前のファイルを、スキル `setup` の候補の列挙と「管理用の YAML に無いファイル」の両方から除外する（コミットする運用の配信元にも適用する） |
| スキル `setup` でローカル運用を用意する | 初回（端末の設定の `sources[]` に `config` がそのフォルダにある行が無いとき）に、運用（コミットする・ローカル運用。既定はコミットする）を聞く。ローカル運用なら `project-index.local.yaml`・`files.local.yaml`・`schemas/*.local.yaml` を作り、`git rev-parse --git-path info/exclude` の指すファイルへ `*.local.*` の 1 行を追加し、端末の設定の行に `storage.type: disk` を記載する。`check_project` には `storage.type` と設定のファイルの絶対パスを指定する。2 回目以降は端末の設定の `storage.type` だけで運用を判定する。検索できるようにするファイルの質問で、Git が無視する生成物・`.env` などを除外するかを確認する |
