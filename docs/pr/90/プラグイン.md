## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 運用の判定 | 端末の設定の `sources[]` に `config` がそのフォルダにある行が無いときだけ、運用（コミットする・ローカル運用。既定はコミットする）を聞く。行があれば、その行の `storage.type` が `disk` ならローカル運用とする | ファイル名では判定しない |
| ローカル運用のファイル | `project-index.local.yaml`・`files.local.yaml`・`schemas/*.local.yaml`（`validators`・`converters` のスクリプトも `*.local.*` の名前）で作る | |
| Git が無視する設定 | `git rev-parse --git-path info/exclude` の指すファイルに `*.local.*` の行が無ければ追加する。`.gitignore` は書き換えない | |
| 端末の設定と検査 | 端末の設定の行に `storage.type: disk` を記載し、`check_project` に `storage.type` と `project-index.local.yaml` の絶対パスを指定する | |
| 候補の列挙 | `*.local.*` の名前のファイルを候補から除外する。ファイルの列挙は `.gitignore` を参照しないため、Git が無視する生成物・`.env` などを除外するかを、検索できるようにするファイルの質問で確認する | 改名の検出はローカル運用でも Git のリネームの検出を使用する |
