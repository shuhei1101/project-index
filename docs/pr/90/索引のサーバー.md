## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 端末の設定 | `sources[].storage.type`（`git`・`disk`）を省略できるキーとして追加する。Git の作業ツリーの外部のフォルダに `git` を指定した行は違反にする | 省略は今の自動の判定 |
| 配信元の組み立て | `disk` の配信元は `is_git`・`repo_root`・`main_root` を無いものとして組み立て、今の Git 管理外の配信元と同じ経路で設定・スキーマ・スクリプト・文書を登録したフォルダから参照する | `default_ref` を使用しない |
| 作業場所の解決 | `disk` の配信元は `worktrees[]` でワークツリーに読み替えない。ワークツリーの作業場所は `scope.write` に該当しなければ参照だけにする | 省略した Git 管理外の配信元の読み替えは残す |
| 書き込み | `disk` の配信元は、`scope.write` に該当すれば登録したフォルダ（クローン本体でも）へ書き込み、文書に `created`・`updated` を追加する。`writable: false` の種類の文書は削除を断る | |
| Git に依る機能 | `disk` の配信元の `ref` の引数と `list_changes` の区間は誤りを返却し、読み取り API の `ref` のクエリは無視して応答の `ref` を空にする。`GET /refs` は `git: false`。`describe(source)` のブランチ・タグ・ワークツリーと、`trace_related` の一緒に変わったファイルは返却しない。ファイルの日時は文書の `created`・`updated` | |
| 反映 | `disk` の配信元の設定の変更は `reload` で読み直す | |
| 端末の設定の API | `GET`・`PUT`・`POST /settings/sources` と `PATCH /settings/sources/{id}` の行に `storage` を加える | dev-docs#235 が前提にする |
| `check_project` | `storage.type` を指定する引数を追加し、設定のファイルの絶対パスも受け付ける | |
| `*.local.*` の除外 | `*.local.*` の名前のファイルを「管理用の YAML に無いファイル」から除外する | コミットする運用の配信元にも適用する |
| 既存機能への影響 | `storage` を省略した配信元の動きは変えない | |

`未確定`: 書き込みで追加する `created`・`updated` の値の形式と、既にある文書を書き換えたときに `created` を追加するか（決める段: インターフェース定義設計）

| 案 | 内容 | メリット | デメリット |
| --- | --- | --- | --- |
| A | ISO 8601 の日時（タイムゾーンつき）。`created` は値が無い文書を書き換えたときも追加する | どの文書もファイルの日時を持つ | 初めて書き換えた時刻が作成の日時になる |
| B | ISO 8601 の日時。`created` は `create` の操作のときだけ追加する | 作成の日時が実際の作成と一致する | 既にある文書の作成の日時は空のまま |

推奨: B

作成の日時に作成でない時刻を入れると、画面と検索の並び替えで誤った値として扱われるため。
