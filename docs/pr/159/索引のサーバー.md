## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| `add_to`・`remove_from` の項目のパス | `#` で始まるパスは `text_edits` と同じく `resolve_ref_path` で種類のスキーマの `x-key` の値から文書の中の配列へ解決し、その配列へ追加・削除する | 要素が無い配列を `add_to` で作れるのは `#` で始まらないパスだけにする |
| 解決できないパスの違反 | `#` で始まらないパスに要素の選び方（`[...]`・`**.`）を含めたとき、解決した値が配列でないとき、`resolve_ref_path` が `InvalidArgumentError` を返却したときは、`add_to.{パス}`・`remove_from.{パス}` の違反にして書き込まない | 違反の文言は `text_edits` の `field` の違反に統一する |
| 名前が `.git` のファイル | `walk_files`・`walk_tree` の `filenames` から、名前が `.git` のファイルを除く | どの深さでも除く。`files`・文書の収集・判定・起動時の警告・`status` の全てで有効になる |
| Git が無視するファイル | `unindexed_files` の候補から、Git の配信元の作業ツリーで Git が無視するファイルを除く。無視の一覧は `git ls-files --others --ignored --exclude-standard` を 1 回呼んで得る | ローカル運用（`storage.type: disk`）と Git 管理外の配信元では今のまま数える。`project-index files` と文書の収集は変えない |
| git の呼び出しの失敗 | 無視の一覧を取れないときは、除かずに今のまま数える | 判定の件数が増えるだけで、配信は止めない |
| `project-index.yaml` の `root` の行 | `exclude` を `["docs/pr/**"]` にする | - |
