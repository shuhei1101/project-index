# 要件

## 要望

| 子 | 完了の条件 |
| --- | --- |
| [#151](https://github.com/shuhei1101/project-index/issues/151) | `add_to`・`remove_from` で `x-key` の値で配列の要素を指せ、文書の中の 1 つの配列に解決できないパスは違反を返却して書き込まない |
| [#154](https://github.com/shuhei1101/project-index/issues/154) | `files`・`check_project`（と起動時の警告・状態の取得）が、名前が `.git` のファイルもフォルダと同じく除外する |
| [#156](https://github.com/shuhei1101/project-index/issues/156) | 判定で `.gitignore` に該当するファイルを数えず、[#155](https://github.com/shuhei1101/project-index/pull/155) で `root` の行の `exclude` に追加したキャッシュ・生成物の行を削除する |

- #151: `add_to`・`remove_from` のキーは、`text_edits[].field` と同じく `#` で始まる参照の型の項目のパスを受け付け、`x-key` の値で要素を指す。`#` で始まらないパスに要素の選び方（`[...]`）を含めると、`add_to.{パス}`・`remove_from.{パス}` の違反を返却し、`applied: true` を返却しない
- #154: 名前が `.git` のファイルは、配信元のどの深さにあっても、ファイルをたどる段階で除く（フォルダの `.git` と同じ範囲）
- #156: Git が無視するファイルを数えないのは「管理用の YAML に無いファイル」の判定だけにする。`project-index files` と文書の収集は、ローカル運用と Git 管理外の配信元で無視の対象のファイルを配信するため、今のまま `.gitignore` を参照しない
