# 要件

## 要望

- `write_docs` の `update` の `remove_from` で、`x-key` を持つオブジェクトの配列（項目のパスを解決した先の配列のスキーマが `x-key` を持つ）に文字列の値を渡すと、`x-key` のキーの値がその文字列と等しい要素を削除する
- `x-key` を持つ配列に渡した値に削除できる要素が無いときは、`applied: true`・`updated` で何も変えずに終わらず、`remove_from.{パス}` の違反を返して書き込まない
- `x-key` を持たない配列と、行の `metadata` の共通のキー（`tags`・`main_tags`）への `remove_from` は今までどおりに削除する
- IF-6 の `operations[].remove_from` と制約に、`x-key` を持つ配列への指定の扱いを記載する

`未確定`: `x-key` を持つ配列の要素そのもの（オブジェクト）を渡したときの扱い（決める段: インターフェース定義設計）

| 案 | 内容 |
| --- | --- |
| A | 今までどおり、渡したオブジェクトと等しい要素を削除する。等しい要素が無ければ違反にする |
| B | オブジェクトを渡すことを違反にし、`x-key` の値（文字列）だけを受け付ける |

推奨: A

要素の全ての項目を渡して削除する今の使い方を断らずに済み、削除できないときに違反を返す扱いは文字列の値と揃うため。
