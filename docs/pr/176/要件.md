# 要件

## 要望

worktree を指した文書の MCP の呼び出しが、その worktree の `project-index.yaml` の文書の行（スキーマの参照・メタデータの対応）で文書を検査・読み取りする。

| ツール | 終わりの条件 |
| --- | --- |
| `write_docs` | worktree で行の `schema.ref` をほかの配信元の別のリビジョンへ変えた後、その worktree を指した書き込みを、変えた後のリビジョンのスキーマで検査する。返却する違反の `schema` も変えた後のスキーマを指す |
| `search_docs`・`trace_related` | worktree で行の `metadata` を変えた（例: `related: refs` を追加した）後、その worktree を指した読み取りが、変えた後の対応で共通のメタデータ（`related` など）を返却し、`trace_related` が関連をたどる |

- worktree の `project-index.yaml` を commit していない状態・commit して push した状態のどちらでも、次の呼び出しから変えた後の行で動く。`reload`・再起動を要さない
- `worktree` を指さない呼び出し（`default_ref`・`ref` を読む呼び出し）は、今までどおり配信中の設定と、指したリビジョンのスキーマで動く
- 同じ文書の読み込み・スキーマの解決を、worktree の行が変わらない限り 2 回目から使い回す（[#82](https://github.com/shuhei1101/project-index/issues/82) の上限の内の返却を保つ）
