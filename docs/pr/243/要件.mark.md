# 要件

## 要望

- `docs/agent-flow/` の `type: skill` のエージェントフローから、`skill.path` の SKILL.md を組み立てて書き出すコマンドを `project-index` に追加する
  - frontmatter: `name`・`description`・`arguments`・`argument-hint`・`allowed-tools`
  - 本文: 工程（`steps[]`）ごとのセクション
  - 組み立てた中身と今の SKILL.md が同じなら書き換えない（続けて 2 回流しても 2 回目は何も変わらない）
  - エージェントフローが読み込めない・スキーマに合わないときは、どの SKILL.md も書き換えずに終了コード 0 以外で終える
- 配信元の設定 `project-index.yaml` の `generators[]` にコマンドを登録し、`agent_flow` の文書の行の `after_write[]` で指して、`write_docs`・`delete_docs` でエージェントフローを書き込んだ後に流れるようにする
- `plugins/project-index/skills/{global-setup,setup,feedback}/SKILL.md` を、コマンドで生成したものに置き換える

`未確定`: コマンドの名前と組み立ての書式（決める工程: インターフェース定義設計）

| 案 | 内容 |
| --- | --- |
| A | サブコマンド `project-index skill-md` にし、組み立ての書式は knowledge の IF-312-1 の約束（frontmatter の並び・生成元のコメント・`## 引数`・`## 手順` の工程のセクション・`ref` の工程の埋め込み）に合わせる |
| B | サブコマンドの名前を knowledge と同じ `build-skills` にし、書式は A と同じにする |

推奨: A

既存のサブコマンド `prompt-doc` が生成物の名前で呼ぶため。書式を knowledge に合わせると、同じテンプレートの `type: skill` から同じ構造の SKILL.md ができる。
