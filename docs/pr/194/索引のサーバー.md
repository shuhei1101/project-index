## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| バリデーション | `records` を持たない行で配置先を決めた後、配置先が行の `paths` のどれにも `full_match` で該当しなければ、配置先を決められない違反にする | `rename` の `new_path` と同じ `DocumentTable.matches` で照合する。除外の名前の照合（既存）の後に照合する |
| エラー返却 | `message`・`rule`・`path` は既存の配置先を決められない違反と同じにする | 修正案は `documents[].paths の先頭のフォルダの階層の glob を ** にしてください` |
| MOD-83 | `new_document_path` の `process`・`exceptions` に配置先が `paths` に該当しないときの違反を、`unit_tests` に `paths: [docs/*/README.md]` と `paths: [docs/*/*.yaml]` の異常系と、`paths: [docs/**/index.yaml]` の正常系を追加する | - |
| IF-6 | `InvalidArgumentError` の `condition` の配置先を決められない条件に、配置先が行の `paths` に該当しないときを追加する | - |
| MOD-71 | `DocumentTable.matches` の `description` に、`records` を持たない行の新しい文書の配置先もこのメソッドで判定することを追加する | - |
| 既存機能への影響 | 配置先が `paths` に該当する行（`docs/**/*.yaml`・`docs/**/index.yaml` など）の戻り値と、既存の違反の条件と修正案は変わらない | 既存の結合テストで回帰を確認する |
