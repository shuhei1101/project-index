# 要件

## 要望

単体テストの層をランナー（`gh workflow run test.yml -f layer=unit`）で回したときに、`test_check_port`・`test_check_port_when_time_wait` が `PortInUseError` で fail しないようにする。

- 完了の条件: 同じ commit で単体テストの層をランナーで回して、`test_serve.py` のポートの確認のテストが fail しない
- 原因の切り分け（テストの準備でポートを払い出してから `check_port` で bind するまでの間に、ほかの接続がそのポートを使用するか・`check_port` の bind の判定か）を先に行い、その結果で修正する範囲（単体テストの準備だけか、`check_port` の処理も含むか）を決める
- `check_port` の振る舞い（`SO_REUSEADDR` を付けて bind し、使用中なら `PortInUseError` を送出する）を変える場合は、起動のポートの確認として利用者に見える振る舞いが変わらないことを確認する
