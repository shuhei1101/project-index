## 変更方針

<!-- table: {"kind": "data"} -->

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 原因の確認 | 外す直前にハンドラを掴んだスレッドが `close()` の後に `emit` する順序を作り、`project-index.log` が開き直されて残ることを確かめる | 確かめた。フィルターで裏のスレッドを `close()` の後まで止めると、`RotatingFileHandler` が `mode='a'` で開き直し、`ResourceWarning: unclosed file` が出る |
| ログのハンドラの閉じ方 | `_setup_logging` が足すファイルのハンドラーを、閉じた後に届いたログを捨ててファイルを開き直さないものにする | `main.py` の中だけで使う `RotatingFileHandler` の派生にする |
| 単体テスト | 閉じた後に裏のスレッドからログを書く順序を固定し、開いたままのファイルが残らないことを確かめるテストを足す | - |
