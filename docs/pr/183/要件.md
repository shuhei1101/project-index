# 要件

## 要望

- IF-6 の `operations[].add_to` と制約に、`x-key` を持つ配列へ既にある `x-key` の値の要素を指定しても、違反にせず重なりを確認せずに末尾へ追加することを記載する
- IF-6 とガイド『文書の MCP』に、`x-key` を持つ配列の要素を置き換える手順を記載する
  - 1 つの `update` に、置き換える要素を `x-key` の値で指す `remove_from` と、追加する要素の `add_to` を指定する（`remove_from` を先に適用する）
  - 配列全体を置き換えるときは `set` を使用する
- `write_docs` の振る舞い（コード）は変えない
