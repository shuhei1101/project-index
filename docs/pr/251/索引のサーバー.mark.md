## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 除く条件の記載 | 配信元の設定の `documents[]` の行に、`search_docs` の `filter` と同じ構造の条件を記載するキーを追加する。比べる項目は共通のキーと種類の列 | キーは `documents[].search_exclude`。既存の `documents[].search` はそのまま残す |
| 条件の検証 | 起動・`reload`・`check_project` で、`filter` と同じ確認で条件の構造の誤りを違反にする | 違反の行の扱いはほかのキーの誤りと同じ。シナリオは SC-10 の既存の異常シナリオ（変えた設定が検証に通らない）に任せ、IF-12・IF-15 の異常系に追加する |
| 既定の結果 | `search_docs`・`list_changes`・`trace_related` の既定の結果から、行の条件に該当する文書を除く | 条件を記載しない行は今と同じ |
| 明示の引数 | 3 つのツールに、除いた文書も含める引数を追加する。付けた結果では、除く条件に該当する文書を見分けられるようにする | 引数は `include_excluded`。`id` で指した取得でも、付けなければ除く。`trace_related` の起点は除かない |
| `list_changes` の区間 | 文書が存在する区間の端の全てで条件に該当する文書を除く。区間の中で該当するようになった・該当しなくなった文書は返却する | 区間の中で追加・削除した文書は、存在する片方の端で判定する |
| 公開ドキュメント | [docs/guide/設定.md](https://github.com/shuhei1101/project-index/blob/90e690a/docs/guide/%E8%A8%AD%E5%AE%9A.md) の `documents[]` の表と、[docs/guide/文書のMCP.md](https://github.com/shuhei1101/project-index/blob/90e690a/docs/guide/%E6%96%87%E6%9B%B8%E3%81%AEMCP.md) の 3 つのツールの引数に追加する | 更新ドキュメント |
