# 要件

## 要望

- 配信元の設定の `documents[]` の行に、既定の検索から除く文書の条件を記載できる
  - 条件は `search_docs` の `filter` と同じ構造（条件・`and`・`or`・`not`）で記載し、共通のキー（`status` など）と種類の列を比べられる
  - 条件を記載しない行と、条件を記載しない配信元の結果は今と変わらない
  - 条件の構造の誤りは、配信元の設定のほかのキーの誤りと同じく起動・`reload`・`check_project` で違反として返却する
- `search_docs`・`list_changes`・`trace_related` の既定の結果から、条件に該当する文書を除く
  - `search_docs` の一覧・件数・集計（`group_by`）・取得のどれでも除く
  - `trace_related` は、除いた文書を関連の相手として返却しない
- 明示の引数を付けた呼び出しでは、除いた文書も検索・取得できる
  - 明示の引数を付けた結果では、除く条件に該当する文書をそれと分かるように返却する
- 条件は配信元の設定の `documents[].search_exclude` に記載し、行全体を検索の対象から除外する既存の `documents[].search` はそのまま残す
- 明示の引数は `search_docs`・`list_changes`・`trace_related` の `include_excluded: true` とし、`filter` の `id` の `eq` で文書を指した取得でも、付けなければ除く
