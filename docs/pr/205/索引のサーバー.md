## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 書き込みの後の通知の判定 | 新規の `POST /_admin/post-write`（[IF-35](https://github.com/shuhei1101/project-index/blob/b42688c/docs/interface/IF-35.yaml)）を追加し、パスごとに配信元・管理用の YAML の範囲と行の有無を判定して、通知の文面を返却する | 管理の MCP のツールにせず、読み取り API にも記載しない |
| 通知の 1 回 | `session_id` と `agent_id` の組ごとに通知したパスをプロセスのメモリに記録し、記録にあるパスは通知しない | 再起動で消える。`/clear`・圧縮の後は `POST /_admin/session-start`（[IF-21](https://github.com/shuhei1101/project-index/blob/9a116fd/docs/interface/IF-21.yaml)）が返却済みの記録と一緒に捨てる |
| 文面 | メタデータを付ける基準を `search_docs` で取得する引数と、`alias_type` の行・`rules.yaml` があるときの 1 行ずつを持つ | プロンプト `content/prompts/hooks/post-write-notice.yaml` で描画する（規約『フック作成ガイド』の rules-01） |
| 配信元の読み込みの間 | 読み込みを待たずに、通知せずに返却する | `POST /_admin/session-start` と同じ |
