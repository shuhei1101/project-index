## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 配信元の設定 | `direct_commit` で、種類ごとに本文の直コミットを断る指定を持たせる。文字列の要素は今と同じく本文を含めて許可する | キーの名前と構造は `未確定`（[要件](./要件.mark.md)） |
| `write_docs` の `commit` | 断る種類の文書で `@body` を変える操作（`set`・`text_edits`・`create`・`replace`）があれば、取得・取り込みの後の検査で違反にしてワークツリーを変えずに返却する | 違反に文書の ID と理由を記載する |
| `delete_docs` の `commit` | 断る種類の文書のうち本文のファイルを持つものを削除する操作を違反にする | 本文のファイルを持たない行の削除は受け付ける |
| 書き込みの API | 書き込みと削除の両方で `write_docs`・`delete_docs` と同じ判定をする | - |
| 既存の振る舞い | 断る指定を記載しない種類と、`commit` を指定しない書き込みは変えない | - |
