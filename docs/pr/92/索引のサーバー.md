### 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 作成 | `op: create` で本文（`@body`）を受けたら、要素を追加し、`body_file` の列のパス（読み込みと同じく YAML のファイルのフォルダから解く）に本文のファイルを作成する | `@body` は種類の列名と重ならない |
| 置き換え・一部の書き換え | `set` の本文は本文のファイルを置き換え、`text_edits` の本文は本文のファイルの一部を置き換える。`old` の一致の判定は今の `text_edits` と同じ | - |
| 版の照合 | `expected_version` を、要素と本文の両方を含めた文書の版で照合する | 読み込みの文書の `version` は要素の値だけ（`loader.py` の `value_hash(record)`）から求めているため、本文のファイルの内容も含める |
| `dry_run` | 本文のファイルの差分を `diff` に含めて返却し、書き込まない | - |
| 書き込めないとき | 本文のファイルのパス（管理用の YAML のフォルダからの相対）が配信元の外を指すなら、要素も本文のファイルも書き込まずにエラーを返却する。要素の YAML と本文のファイルは、両方の検査に通ってから書き込む | `atomic` の扱いは今の書き込みと同じ。`scope.write` は作業場所（`cwd`）の glob で、今の書き込みの確認がそのまま当たる |
| 削除 | `delete_docs` で、要素と一緒に本文のファイルも削除する | 要素だけを除くと、本文のファイルが管理用の YAML に無いファイル（`unindexed_files`）として残るため |
| `body_file` を持たない行 | 要素だけを書き換える今の振る舞いと版を変えない | - |
