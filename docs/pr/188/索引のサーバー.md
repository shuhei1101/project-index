## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| エラー返却 | `_undecided` が文書の行の `records` の有無で `fix` を分ける。`records` を持つ行は `documents[].paths の先頭を glob を含まない 1 つのファイルにしてください`、持たない行は今の `documents[].paths の先頭を glob にしてください` | `message`・`rule`・`path` とエラーになる条件は変えない |
| MOD-83 | `new_document_path` の `process` の 4 の修正案の記載を `records` の有無で分け、`unit_tests` に配置先を決められないときの 2 件（`records` を持つ行で先頭が glob・持たない行で先頭が glob を含まない）を追加する | - |
| IF-6 | `flows` に「異常系（配置先を決められない・InvalidArgumentError）」を追加する。`records` を持つ行で `paths` の先頭が glob のとき、違反の `path` が `operations[0].kind`、`fix` が glob を含まない 1 つのファイルにする旨であることと、何も書き込まないことを期待値にする | テストは結合テストに 1 件追加する |
| 既存機能への影響 | `records` を持たない行の修正案と、配置先を決められた場合の戻り値は変わらない | - |
