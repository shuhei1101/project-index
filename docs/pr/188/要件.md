# 要件

## 要望

`write_docs` の `create` で新しい文書の配置先を決められないときの修正案（違反の `fix`）を、文書の行が `records` を持つかで分ける。

| 文書の行 | 配置先を決められない条件 | 修正案 |
| --- | --- | --- |
| `records` を持つ | `paths` が空か、先頭が glob を含む | `documents[].paths の先頭を glob を含まない 1 つのファイルにしてください` |
| `records` を持たない | `paths` の先頭が glob を含まない | `documents[].paths の先頭を glob にしてください`（今のまま） |

- エラーの `message`・違反の `rule`・`path`（`operations[{i}].kind`）と、エラーになる条件は変えない
- モジュール構成 MOD-83 の `new_document_path` の `process`・`exceptions`・`unit_tests` に、`records` の有無で分けた修正案を記載する
- インターフェース定義 IF-6 に、配置先を決められないときのフロー（`records` を持つ行）を追加する。IF-6 には今、配置先を決められないエラーの記載が無い
