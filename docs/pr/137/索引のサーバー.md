## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| `project-index migrate` | 再読み込みした `original` を、L115 の書き出しに渡す | L107 の比較はファイルへ書かず、比べる両方を同じ既定の字下げで書き出すため渡さない |
| 端末の設定の保存 | `_write_and_reload` が書き換える前の端末の設定の文字列を受け取り、`original` に渡す | 呼び出し元の `save_sources`・`add_source`・`patch_source`・`delete_source` は書き換える前に端末の設定を読んでいる |
| `write_nav` | 読み込んだ `project-index.yaml` の文字列を、書き出しの `original` に渡す | 応答の `nav`（L666）はファイルへ書かないため変えない |
| 確認の時点の記録 | 読み込んだ管理用の YAML の文字列を、書き出しの `original` に渡す | - |
| 既存機能への影響 | 字下げ無しの配列を持つファイルを 4 つの呼び出し元で書き換えると、今は字下げありに揃うが、変更後は元の字下げのまま残る | 字下げの検出は #121 の `dump_roundtrip` のまま変えない |
