# 要件

## 要望

次の 4 つの呼び出し元が既にあるファイルを書き換えるとき、読み込んだ元のファイルの文字列を `dump_roundtrip` の `original` に渡し、元のファイルの配列の字下げを保つ。
元のファイルが `- ` を字下げ無しで並べていても、字下げありで並べていても、書き換えた後のファイルで変えたキーの行だけが差分になる。

| 呼び出し元 | 箇所（develop [4472517](https://github.com/shuhei1101/project-index/commit/4472517)） | 書き換えるファイル |
| --- | --- | --- |
| `project-index migrate` | `src/project_index/features/migrate/service.py` L107・L115 | 端末の設定・配信元の設定 `project-index.yaml` |
| 端末の設定の保存 | `src/project_index/features/settings/service.py` L170（`_write_and_reload`） | 端末の設定 `settings.yaml` |
| `write_nav` | `src/project_index/features/admin/service.py` L628 | 配信元の設定 `project-index.yaml` |
| 確認の時点の記録 | `src/project_index/features/checkpoint/record.py` L56 | 管理用の YAML |

`migrate` の L107 は、読み込んだ後に変わっていないかを確かめる比較で、比べる両方の書き出しに同じ `original` を渡して字下げを揃える。
