## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 除外の条件（#102） | `is_excluded_file` をバイナリ・空のファイル・`*.local.*` だけにし、`files` と `check_project` の `unindexed_files` に同じく効かせる | IF-17・IF-12 |
| 既存の配信元への影響（#102） | 除外の条件を狭めるため、既存の配信元で `check_project` の `unindexed_files` が増える（この配信元では再エクスポートだけの `__init__.py`・ロック）。管理用の YAML への行の追加は [#104](https://github.com/shuhei1101/project-index/issues/104) で行う | MOD-26・MOD-27・MOD-89・MOD-106-6 の単体テストの前提も合わせて修正した |
| 関連の候補の取り出し（#107） | Markdown と YAML の本文から、配信元の中のファイルを指すパスとリンクを取り出し、ファイルごとに指す先を出す `project-index links` を追加する | IF-113-1 |
| メタデータの偏りの洗い出し（#110） | 管理用の YAML の行と行の案から、ほぼ同じ `description` の組・1 件だけのタグ・半数以上に付くタグを出す `project-index skew` を追加する | IF-113-2。しきい値は [しきい値の測定](./しきい値の測定/README.md) |
