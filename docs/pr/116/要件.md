# 要件

## 要望

- テスト実行方法の層ごとに、判定フローチャート『テストの実行場所』で実行場所（`runner` / `local`）を決めて `location` に記載する。lint の層は `local` にする
- `runner` の層は、workflow `.github/workflows/test.yml` を `workflow_dispatch` で起動し、終わるまで待ってログを取得する 1 コマンドを `run_runner` に記載する。workflow はインターフェース定義がレビューに合格してから作る
- `runner` の層も、手元の全件実行（`run_all`）・個別実行（`run_one`）のコマンドを残し、ランナーで回せないときは手元で回す
- 層の中の一部のテストだけが手元で用意できるものを要する場合、そのテストにマーカーを付け、ランナーの全件実行から実行器の選び分けで除く
- workflow は develop にあるものだけを起動できるため、この作業 PR の中のテストは手元の全件実行で回し、理由をログに記録する。ランナーと手元の skip の件数の照合は、develop へ入った後に初めてランナーで回す作業 PR で行う
