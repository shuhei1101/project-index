# リビジョンを指して文書を読むとき、converters[] のスクリプトへ読んでいる commit を環境変数で渡す

## 概要

`ref`・`default_ref` で文書を参照するとき、`converters[]` のスクリプトが、参照しているリビジョンの本文以外のファイルを参照できるようにする。

## 背景

[Issue #100](https://github.com/shuhei1101/project-index/issues/100) の要望。利用する側は [shuhei1101/ai-monitor#3546](https://github.com/shuhei1101/ai-monitor/pull/3546)。
変換はクローン本体の直下で動き、スクリプトは参照している commit を受け取らないため、本文以外のファイルをクローン本体が checkout しているブランチの作業ツリーから参照する。
AI Monitor のフェーズの変換は、dev-docs の画面でブランチ・`develop` のフェーズを開くと、本文は指したリビジョン、参照先のフェーズは `master` の組み合わせの Markdown を返却する。
