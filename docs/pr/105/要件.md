# 要件

## 要望

文書の取得で Git の配信元を参照するとき（`ref` を指したとき・省いて `default_ref` で参照するとき）、`converters[]` のスクリプトへ、参照しているリビジョンを解いた commit の SHA（40 文字）を環境変数 `PROJECT_INDEX_COMMIT` で指定する。

| 対象 | 終了の条件 |
| --- | --- |
| 指定するとき | 読み取り API の文書の取得で `ref` を指したとき・`ref` を省いて `default_ref` で参照するとき、スクリプトの環境変数 `PROJECT_INDEX_COMMIT` が、そのリビジョンを解いた commit の SHA（40 文字）になる |
| 指定しないとき | disk の配信元・Git の管理外の配信元と、`try_convert` は、スクリプトの環境に `PROJECT_INDEX_COMMIT` が無い。サーバーのプロセスの環境に `PROJECT_INDEX_COMMIT` があっても引き継がない |
| 作業ディレクトリ | 今と同じクローン本体の直下のまま変えない |
| 他の環境変数 | サーバーのプロセスの環境変数（`PATH` など）は今と同じくスクリプトへ引き継ぐ |
| キャッシュ | `cache: true` の行のキャッシュのキーは変えない |
| 利用者向けのドキュメント | `converters[]` の説明に、`PROJECT_INDEX_COMMIT` を指定するとき・指定しないときと、スクリプトが `git show {commit}:{path}` でそのリビジョンの本文以外のファイルを参照できることを加える |
