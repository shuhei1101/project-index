## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| スクリプトの実行 | `run_script` に、サーバーの環境変数へ追加・上書きする環境変数の引数を加える。省けば今と同じ環境で動かす | `validators[]`・`generators[]`・mdmark の点検は引数を省き、動作を変えない |
| 変換 | `target.commit` があれば `PROJECT_INDEX_COMMIT` に commit を入れて動かし、無ければサーバーの環境の `PROJECT_INDEX_COMMIT` を除外して動かす | `cwd`・`at`・キャッシュのキーは変えない |
| 文書の取得 | `ref`・`default_ref` で参照した `converters[]` の変換で、スクリプトが受け取る `PROJECT_INDEX_COMMIT` を応答の `ref` を解いた commit にする制約と正常系を加える | - |
