## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 計測 | 設計の前に、負荷をかけた状態と負荷の無い状態で、`_run` の配信元の読み込みの待ち・`asyncio.to_thread` のスレッドの待ち・`store.load`・`find_page`・`row_schema`・`_metadata`・応答の直列化の各段の時間を測り、結果を計画書に記載する | 計測は ai-monitor の配信元の `docs/data/DATA-3694-1.yaml` の 2 回目以降の取得 |
| 性能 | 計測で時間を占めた段を短くする（使い回せる結果のキャッシュ・取り合いの除去・スレッドの待ちの回避など、方法は計測の結果で決める） | 変更の後の所要時間を同じ時間帯の変更の前の値と比べ、NFR-1 に決定値を記載する |
| 既存機能への影響 | 応答の形・404・504 の振る舞いは変えない | 文書の一覧・検索の読み取り API も同じ `_run` を通るため、共通の段を変えたときは影響を計画書に記載する |
