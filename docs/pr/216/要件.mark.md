# 要件

## 要望

読み取り API の文書の取得で、文書 1 件の取得にかかる時間の内訳（配信元の読み込みの待ち・関所の待ち・スレッドの待ち・文書の引き当て・種類のスキーマ・メタデータ・応答の直列化）を計測し、負荷の高い間に時間を占めている段を短くする。

- 計測は、端末に負荷をかけた状態と負荷の無い状態で、ai-monitor の配信元の `docs/data/DATA-3694-1.yaml` を 2 回目以降に取得したときの各段の時間を同じ時間帯に測る
- 変更の後、負荷をかけた状態の文書 1 件の取得の所要時間が、同じ時間帯に測った変更の前の値より短くなり、決定値を非機能要件（NFR-1）に記載する
- 応答の形（`DocumentValueResponse` の項目）は変えない
