## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 文書の一覧（IF-24） | 各要素に、`Document.metadata`（`resolve_metadata` の結果）をそのまま入れた `commonKeys` を追加する | クエリ `common_keys=true` のときだけ入れ、それ以外は `null` |
| 文書の取得（IF-25） | `metadata` に、文書の一覧と同じ `commonKeys` を追加する | 1 件だけなので常に返却する |
| キーの名前 | 追加する項目の中のキーは `METADATA_KEYS` の名前のままにし、camelCase にしない | `value` の中身と同じ扱い |
| 既存機能への影響 | 既存の応答のキーは残して追加するだけにする | 破壊的変更なし |
| 性能 | 文書のストアが読み込み済みの `Document.metadata` から返却し、文書ごとに `resolve_metadata` を呼び直さない | - |
