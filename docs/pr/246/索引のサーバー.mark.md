## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 削除の時点の検査 | `validators[].on` に `delete` を追加する。`delete_docs` はファイルを削除する前に、`targets` の文書ごとに、その種類の行の `on` に `delete` を持つ `validators[]` を実行する。標準入力に文書の YAML、環境変数 `PROJECT_INDEX_VALIDATE_ON` に `delete`、`PROJECT_INDEX_DELETE_IDS` に `targets` の全ての `id` を指定する | [IF-7](https://github.com/shuhei1101/project-index/blob/8065681/docs/interface/IF-7.yaml) の制約「削除の前の検査」 |
| 断ったときの返却 | `ValidationFailedError` で、その文書の添字の違反として返却する。`atomic: false` は違反のあった文書を `failed` にして `PROJECT_INDEX_DELETE_IDS` から除き、新規の違反が出なくなるまで残る文書を再検査する | - |
| SKILL.md の検査 | `project-index skill-md --check` は `PROJECT_INDEX_VALIDATE_ON` が `delete` のとき、`PROJECT_INDEX_DELETE_IDS` の文書を除いて全ての `type: skill` を組み立て、標準入力の文書を指す解決できない `ref` だけを違反にする。違反の `rule` に参照しているエージェントフローのパスと `id`・`ref` を入れる | [IF-37](https://github.com/shuhei1101/project-index/blob/8065681/docs/interface/IF-37.yaml) の制約「削除の検査」 |
| 配信元の設定 | `project-index.yaml` の `skill-md-check` の `on` を `[write, delete]` にし、設定のスキーマ（`schemas/project-index.schema.json`）の `on` の値に `delete` を追加する | - |
| 参照元ごと削除 | 参照しているエージェントフローも同じ `targets` にあれば、残るエージェントフローに未解決の `ref` が無いので断らない | - |
| 対象外の削除 | `on` に `delete` を持たない `validators[]` は削除で実行しない。どの `ref` からも指されないエージェントフローは今までどおり削除する | - |
| 処理時間 | `script_timeout_sec` と書き込みの期限までの残りの時間の短い方で止める | [非機能要件](https://github.com/shuhei1101/project-index/blob/9d95b0f/docs/nonfunctional/NFR-1.yaml) のスクリプトの制限時間 |
