## テスト結果

### 単体

なし。公開ドキュメントのページの改名とリンク・配信元の設定の `nav` の修正だけで、規約『V字モデル』の対応表で関係する単体テストが無い。

### 結合

なし。同じ理由で、関係する結合テストが無い。改名後のページが配信され、旧パスを指す文書が残っていないことは、作業ブランチを `ref` にした `search_docs` で確認した。
