## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 往復編集の書き出し | `dump_roundtrip` に引数 `original`（元の文字列）を追加し、元の文字列から配列の字下げ（`- ` を親のキーと同じ列に置くか、字下げするか）を検出して同じ字下げで書く。`original` が無いとき・配列が見つからないときは `YAML_INDENT` で書く。辞書の字下げの幅は `YAML_INDENT` の 2 のまま | `apply_operation` は内容を複製し、`replace` は新しい辞書を作るため、読み込んだ値に字下げを持たせる方式では書き出しまで残らない。元の文字列を引数で受ける |
| `write_docs`・`delete_docs` の書き出し | 既にあるファイルを書き換えるとき（`update`・`replace`・`records` への `create`・`records` の要素の削除・`on_referenced: unlink` で参照元の `related` から行を除くとき）に、作業ツリーの文字列を `original` に渡す。IF-6 に結合テスト `test_normal_when_indent_preserved` を追加する | `items:` の直下に `- ` を字下げ無しで並べる文書（[72ad6fa](https://github.com/shuhei1101/project-index/commit/72ad6fadb49bc874b33e5ab33a7e5eec9da7a7e3) の `docs/interface/index.yaml`・IF-6 の結合テストの文書 1）と、字下げありで並べる文書（`docs/layout/LAY-73-1.yaml`・IF-6 の結合テストの文書 2）の両方で、追加した要素の行だけが差分になる |
| `test_normal_when_rechecked_after_write` | memo の doc-1 の `related` に無い文書 doc-9 を指させ、`write_docs` の `update`（`unset: [related]`）で「どの文書にも該当しない関連」の警告が消えることを確かめる。書き込みの前の `describe` も `checking: false` を待ってから呼ぶ | `body_file` の行の `create` は作業ツリーに既にある本文のファイルを受け付けない（#92）ため、管理用の YAML に無い既存のファイルの行は `write_docs` で作れない。実装は変更しない |
| `test_error_when_unexpected` | 偽の git を、`archive` の呼び出しで待たずに失敗する形にする | IF-2 の結合テストの準備と期待を合わせる |
| `test_normal_when_warned` | 管理の MCP の `status` が `checking: false` を返してから `describe` を呼ぶ | `describe` は起動の後の裏の検査の結果を参照するため。実装は変更しない |
| `test_error_when_invalid_config` | 違反の件数の表記を確かめる期待にする | 一時フォルダのパスに依存させない |
| 既存機能への影響 | 字下げ無しの配列を持つ既存のファイルを往復編集で書き換えると、今は字下げありに揃うが、変更後は元の字下げのまま残る | 書き出しの結果が変わるのは往復編集の書き出しだけ |
