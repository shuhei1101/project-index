## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 往復編集の書き出し | `load_roundtrip` で読んだ元の文字列から配列の字下げ（`- ` を親のキーと同じ列に置くか、字下げするか）を検出して値に持たせ、`dump_roundtrip` で同じ字下げで書く。元の文字列が無いときは `YAML_INDENT` で書く | `write`・`migrate`・`settings`・`admin`・`checkpoint` の往復編集の書き出しが全て対象になる |
| `write_docs` の書き出し | 既存の文書の `update`・`replace` で、元のファイルの字下げを維持する | `docs/interface/index.yaml`（字下げ無し）と `docs/layout/LAY-73-1.yaml`（字下げあり）の両方で、追加した行だけが差分になる |
| `test_normal_when_rechecked_after_write` | `create` の `data` に `@body` を追加する | 実装は変更しない |
| `test_error_when_unexpected` | 偽の git を、`archive` の呼び出しで待たずに失敗する形にする | IF-2 の結合テストの準備と期待を合わせる |
| `test_normal_when_warned` | 1 回目だけ fail する原因を切り分けて、テストか警告を集める処理を修正する | 原因は未特定 |
| `test_error_when_invalid_config` | 違反の件数の表記に当てる期待にする | 一時フォルダのパスに依存させない |
| 既存機能への影響 | 字下げ無しの配列を持つ既存のファイルを往復編集で書き換えると、今は字下げありに揃うが、変更後は元の字下げのまま残る | 書き出しの結果が変わるのは往復編集の書き出しだけ |
