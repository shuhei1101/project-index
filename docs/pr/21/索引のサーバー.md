### 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 配信元の設定のキー | `paths[]` の基準のフォルダを、設定ファイルのフォルダからの相対パスで指定するキー `paths_base` を追加する。省略時は設定ファイルのフォルダ | - |
| 基準のフォルダの検証 | 基準のフォルダが無い、または設定ファイルのフォルダより上でない（下・横を指す）ときは違反にする | - |
| `paths[]` の解き方 | 基準のフォルダから解き、`..` で基準のフォルダの外を指す `paths[]` は今と同じく違反にする。返却する文書のパスは基準のフォルダからの相対パス | `paths[]` 以外の相対パスは今どおり設定ファイルのフォルダから解く |
| リビジョンからの読み取り | `default_ref` の commit から読むときも、基準のフォルダからの相対パスで読む | `_commit_reader` |
| 既存機能への影響 | キーを省いた設定は今と同じ解き方で、既存の配信元はそのまま配信する | - |
