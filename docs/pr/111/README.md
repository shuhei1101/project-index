# 開発ドキュメントのタブとサイドバーを規約『開発ドキュメントのナビゲーション』に従って nav で定義し、目次を並べない

## 概要

dev-docs の画面で、この配信元（`project-index`）のタブを起点になるものから参照用の資料の順に 7 件以下で並べ、サイドバーをグループでまとめ、フォルダの目次を並べない。

## 背景

[Issue #84](https://github.com/shuhei1101/project-index/issues/84) の要望。
`project-index.yaml` が `nav` を持たないため、`documents[]` の行ごとに 15 件のタブが並び、画面の幅に収まらない。起点になる公開ドキュメントのタブが右の方にあり、目次（`index` の行）もタブとサイドバーに並ぶ。
決まりは [shuhei1101/knowledge#421](https://github.com/shuhei1101/knowledge/issues/421) で規約『開発ドキュメントのナビゲーション』として登録済み。
