## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| ファイルの日時 | `file_dates` の `git log` に `--diff-merges=dense-combined` を付け、マージ commit で全ての親と異なるファイルをその commit の日時として数える | どれかの親と同じファイルは、その親の側で変えた commit の日時のまま |
| 文書の取得の `updated_at` | `ref` のある読み取りの場所では作業ツリーのファイルを stat しない。日時を持たない文書は、文書のストアの `file_updated` でそのリビジョンでファイルを最後に変えた commit の日時を入れ、それも無ければリビジョンの commit の日時を入れる | 読み取り API は `ref` を省いても `default_ref` を指すので、Git の配信元は同じ取り方になる。Git の管理外の配信元は今のまま |
| YAML を読めなかったファイル | 通常の文書と同じ取り方で `updated_at` を入れ、`conversionError` つきの 200 を返却する | - |
| 既存機能への影響 | 応答のキーと型は変えない。検索の `updated`・`created` も同じ `file_dates` の値を使用するため、マージ commit で追加したファイルが日時を持つようになる | - |
| 性能 | `--diff-merges=dense-combined` を付けても `file_dates` の `git log` の所要時間は増えない（下の表）。NFR-9 の初回の読み込みを含む要求の 30.72 秒に加えても 1 分に収まる | - |

### `file_dates` の所要時間

2026-11-25 に、`git log --format=%x00%cI --name-only --no-renames develop` と、同じコマンドに `--diff-merges=dense-combined` を付けたものを 3 回ずつ実行した（git 2.43.0）。
