## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| ファイルの日時 | `file_dates` の `git log` が、マージ commit で親から変わったファイルも commit の日時として数える | 数え方（最初の親との差分だけか、全ての親との差分か）はモジュール構成設計で決める |
| 文書の取得の `updated_at` | `ref` のある読み取りの場所では作業ツリーのファイルを stat しない。日時を持たない文書は、そのリビジョンでファイルを最後に変えた commit の日時を検索して入れる | `ref` を省いた読み取りと Git 管理外の配信元は今のまま |
| YAML を読めなかったファイル | 通常の文書と同じ取り方で `updated_at` を入れ、`conversionError` つきの 200 を返却する | - |
| 既存機能への影響 | 応答のキーと型は変えない。検索の `updated`・`created` も同じ `file_dates` の値を使用するため、マージ commit で追加したファイルが日時を持つようになる | - |
