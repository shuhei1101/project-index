# 要件

## 要望

- 配信元から削除した `type: skill` のエージェントフローの `skill.path` の SKILL.md を削除し、生成元のエージェントフローが無い SKILL.md を配信元に残さない
  - `delete_docs` でスキルのエージェントフローを削除した呼び出しの後に、その SKILL.md が無い
  - `commit` を指定した削除では、SKILL.md の削除も同じコミットに入る
- 残っている `type: skill` のエージェントフローの SKILL.md と、エージェントフローから生成していないファイルは削除しない
- 削除の仕組み（生成のモードで消す・`delete_docs` の後に消す 等）と、生成した SKILL.md の見分け方は設計の工程で決める
