## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 生成元の無い SKILL.md の削除 | `project-index skill-md` の生成のモードで、組み立てたどのスキルの `skill.path` でもない SKILL.md を削除する。削除・`type` の変更・`skill.path` の変更の後に残る前の SKILL.md を同じ処理で削除する | [IF-37](https://github.com/shuhei1101/project-index/blob/8335276/docs/interface/IF-37.yaml) の制約「生成元の無い SKILL.md の削除」 |
| 生成した SKILL.md の見分け | 組み立てた SKILL.md が持つ生成元のコメント（配信元の直下からのエージェントフローのパス）で、エージェントフローから生成したファイルだけを削除の対象にする。コメントのパスが `agent_flow` の `paths` に該当するものに絞る。配信元の直下から名前が `SKILL.md` のファイルを探し、`.` で始まるフォルダの配下は除く | - |
| 直コミット | 削除した SKILL.md を生成物の変更として同じコミットに含める | IF-7 の `commit` の制約のまま |
