## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 使用できる項目 | スキーマの配列の `items` のキーを `{配列のキー}[].{キー}`（`uses[].id`）の項目として一覧に加える。型は要素のキーの型 | `未確定`（要件の項目のパスの記載方法） |
| 項目の値 | `uses[].id` の値は文書のストアの `get_field` で要素ごとの値の配列として取得し、配列の項目と同じく要素ごとに比べる・数える | - |
| エラー返却 | 一覧に無い項目は今のとおり「知らない項目です」にし、近い項目の候補に `uses[].id` を出す | - |
| 既存機能への影響 | 共通のキー・`metadata` で対応付けたキー・オブジェクトのキー（`category.id`）の値と比べ方は変えない | - |
