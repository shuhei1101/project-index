# 要件

## 要望

- 配信元の設定（`project-index.yaml`）に、省略できるキー `when`（使う場面の文字列の並び）を追加する。スキーマ（`src/project_index/schemas/project-index.schema.yaml`・`schemas/project-index.schema.json`）と設定の型に足し、既存の設定の読み方は変えない
- `describe` の配信元の一覧（引数なし）と作業範囲の外の一覧（`outside_scope: true`）に、配信元ごとの `when` を出す。`describe(source)` も `when` の全ての行を返す
- 文書の MCP の `initialize` の instructions に、配信元の ID と `when` の 1 行目の一覧を加える。instructions 全体を 4,096 字以内に収め、超える分の配信元は一覧から外して `describe(outside_scope: true)` へ案内する
  - 設計で 4,096 字に収められないと分かったら、ユーザーへ確認する
- SessionStart での案内は対象外（D-152 の決定のうち SessionStart の部分は行わない）

instructions の配信元の一覧は、単一 UC シナリオ（[SC-6](../../scenario/SC-6.yaml)）で次のとおり決めた。

| 論点 | 決めた内容 | 理由 |
| --- | --- | --- |
| 一覧を描画する時点 | 接続（`initialize`）ごとに、`describe` と同じく `default_ref` の commit を確認し、変わっていれば配信元を組み立て直してから描画する | `describe` と instructions で、`when` の書き換えが反映される時点が揃う |
| 一覧に載せる配信元 | 配信中で `when` を持つ全ての配信元を、端末の設定の `sources[]` の順に並べる | instructions は接続の時点で作業場所（`cwd`）を受け取らず、作業場所で絞り込めない |
| 4,096 字を超えるとき | 端末の設定の順に収まる配信元まで載せ、載せなかった件数と `describe(outside_scope: true)` の案内を添える | - |
