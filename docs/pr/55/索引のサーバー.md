## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 配信元の設定のスキーマ・型 | 省略できるキー `when`（空でない文字列の並び。既定は空の並び）を足す | 省略した既存の設定は今のまま読める |
| `describe()`・`describe(outside_scope: true)` | 配信元の一覧の各行に `when` を出す（`markdown` は列、`json` はキー） | `description` が空でも `when` だけを出せる |
| `describe(source)` | 説明書と並べて `when` の全ての行を返す | - |
| 文書の MCP の instructions | 既存のプロンプトの後ろに、配信元の ID と `when` の 1 行目の一覧を加える。全体が 4,096 字を超える分の配信元は一覧から外し、外した件数と `describe(outside_scope: true)` への案内を添える | `when` を持たない配信元は一覧に載せない。描画する時点と載せる範囲は要件.md |
| 公開ドキュメント | `docs/guide/設定.md` の配信元の設定のキーの表と、`docs/guide/文書のMCP.md` の instructions と `describe` の出力の説明に `when` を足す | - |
