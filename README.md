# project-index

文書とソースコードの索引・検索・書き込みを提供するサービス。

配信元（文書のまとまり）の文書を索引にし、エージェントには文書の MCP・管理の MCP で、dev-docs の画面のサーバーには読み取り API で提供します。

```text
/plugin marketplace add shuhei1101/project-index
/plugin install project-index@project-index
/project-index:global-setup
```

入れ方と使い方は [project-indexを入れる](./docs/guide/project-indexを入れる.md)、ツールと API の一覧は [リファレンス](./docs/guide/リファレンス.md) にあります。

ドキュメント: https://shuhei1101.github.io/project-index/
