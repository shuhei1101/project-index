# 要件

## 要望

設計書も実装も無い project-index のリポジトリに、dev-docs から機能を移す後続の作業（[shuhei1101/dev-docs#114](https://github.com/shuhei1101/dev-docs/issues/114)）が前提にする土台を用意する。
新しい機能は作らない。

| 対象 | 用意するもの |
| --- | --- |
| アーキテクチャ図 | Issue 本文のコンポーネントの表（文書の MCP・管理の MCP・プラグイン・読み取りAPI・問い合わせ・書き込み・配信元と権限・索引・会話記録・スクリプトの実行）と、外部の利用者（Claude Code のセッション・AI Monitor と aituber のエージェント・dev-docs の画面のサーバー） |
| 非機能要件 | 動作環境（手元の端末で常駐するサーバー・Python 3.14）と、データの保存先 |
| データの保存先 | 端末の設定 `${XDG_CONFIG_HOME:-~/.config}/project-index/settings.yaml`・状態のフォルダ `${XDG_STATE_HOME:-~/.local/state}/project-index`・各リポジトリの配信元の設定 `project-index.yaml`・`project-index.local.yaml` |
| ドキュメントの骨格 | `dev/設計書/` と `docs/` の目次、ルール索引、`CLAUDE.md`、`nav.project.yml` |
| パッケージの骨組み | uv で管理する Python 3.14 のパッケージ `src/project_index/` と起動の入口。依存は dev-docs と同じく FastAPI・MCP（Streamable HTTP）・ruamel.yaml・jsonschema |
| プラグインの骨組み | Claude Code のプラグイン `plugins/project-index/`（MCP の接続・フック・スキルの置き場）と、マーケットプレースの設定 |
| `README.md` | 立ち上げ後の構成とセットアップの入口 |

コンポーネントの名前は、配信元・索引・会話記録・問い合わせ・読み取りAPI を使う（D-156〜D-160）。

## スコープ外

| 項目 | 理由 | 対応予定 |
| --- | --- | --- |
| dev-docs の機能・コード・設計書（分類『文書のMCP』『検索』『書き込み』など）の移植 | Issue 本文で後続の作業とされている | [shuhei1101/dev-docs#114](https://github.com/shuhei1101/dev-docs/issues/114) |
| dev-docs・alias-inject の配信元の設定のファイル名を `project-index.yaml` へ変える作業 | 各ツールのリポジトリの変更で、このリポジトリで完結しない | 起票予定 |
