# 要件

## 要望

`dev/` を廃止し、文書を `docs/` と `schemas/` へ移す。
構成は [shuhei1101/ai-monitor#3307](https://github.com/shuhei1101/ai-monitor/pull/3307) の [dev/pr/3307/モニター.md](https://github.com/shuhei1101/ai-monitor/blob/cc97586e6966658ead68a3642c23dcf16b01e613/dev/pr/3307/%E3%83%A2%E3%83%8B%E3%82%BF%E3%83%BC.md) の `### 種類のフォルダ` と `### 置き場所の規則` に統一する。

終わりの条件:

- `dev/` の下に `dev/pr/` のほかのファイルが残っていない
- `docs/` の下は種類のフォルダ（`architecture`・`nonfunctional`・`module`・`config`・`test-procedure`・`dev-command`・`external-api`・`library`・`guide`）と、`_` で始まる Pages の共通レイアウトだけで、種類のフォルダの中にフォルダが無い
- YAML の設計書のファイル名が `{ID}.yaml`（言語の接尾辞を持つものは `{ID}.{lang}.yaml`）になっている
- Schema が `schemas/{kind}.schema.yaml` にある
- 全ての文書がメタデータ `visibility` を持ち、今の `docs/` の下の文書は `public`、`dev/` から移した文書は `internal` になっている
- `docs/_config.yml` の `exclude` に、`internal` の文書だけを持つ種類のフォルダと `pr/`・`mock/`・`generated/` が載っている
- `CLAUDE.md`・`README.md`・`rules.yaml`・`dev-docs.yaml`・`.gitignore`・`pyproject.toml`・テスト・コードに、移す前のパスを指す記述が残っていない（`dev/pr/` を指す記述を除く）
- `dev-docs.yaml` の `paths` で、移す前と同じ件数の YAML の設計書を検索できる（目次は、サブフォルダの目次をまとめた分だけ減る）
- `dev-docs.yaml` の `docs/guide/files.yml` を読む文書の行で、`docs/guide/` の Markdown を `visibility`・`category` つきで検索できる

`dev/pr/` は移さない。
稼働中のモニターは ai-monitor#3307 のマージまで `dev/pr/` を参照し、`docs/pr/` への移動は #3307 の反映作業『open の作業 PR の PR ドキュメントの移動』が行う。

この PR はレビューに合格した後もマージしない。
マージは ai-monitor#3307 のマージの後に、#3307 の反映作業『監視対象のプロジェクトの移行の PR のマージ』で ai-monitor の planner が行う。
